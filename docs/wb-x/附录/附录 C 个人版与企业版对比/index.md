# 附录 C 个人版与企业版对比

WorkBuddy 提供个人版和企业版两个版本。个人版面向个人用户，适合独立处理日常工作任务；企业版面向团队和组织，在数据安全、协作管理和成本管控方面提供了完整的企业级能力。

本附录从功能对比、安全体系、量化价值和升级路径四个方面，帮助你判断哪个版本更适合自己的使用场景。

## 功能对比总览

| 对比维度 | 个人版 | 企业版 |
|---------|--------|--------|
| 知识库能力 | ⚠️ 通用技术回答 | ✅ 可构建企业私有知识库 |
| 多人协作 | ❌ 单人使用 | ✅ 团队共享专家团与 Skill |
| 数据安全 | ⚠️ 数据可能用于模型训练 | ✅ 企业级数据隔离，不用于训练 |
| 管理后台 | ❌ 无 | ✅ 云端后台，实时监控使用情况 |
| 权限控制 | ❌ 无 | ✅ 精细化角色权限，按需分配 |
| Token 管理 | ❌ 无法统一管控 | ✅ 集中采购、分配、限额 |
| 模型配置 | ⚠️ 有限模型 | ✅ 多模型开放集成，按需切换 |
| 定制化 | ❌ 无 | ✅ 自定义专家团、自定义 Skill |
| 客户支持 | ⚠️ 社区支持 | ✅ 专属客户成功团队 + 培训 |
| ROI 追踪 | ❌ 无法评估 | ✅ 后台数据看板，清晰可见 |

一句话总结：**个人版解决的是"一个人怎么用 AI"；企业版解决的是"一家公司怎么用 AI"。** 这是两个完全不同的问题。

## 企业级安全：四管体系

个人版在使用 AI 时，上传的合同、财务报表、客户数据等敏感文件存在被用于模型训练的风险。企业版通过"四管"体系，从人、智能体、Token 和数据四个维度建立完整的安全管控。

| 管控维度 | 功能说明 | 为什么重要 |
|---------|---------|-----------|
| **管人** | 角色权限、部门分组、使用日志 | 谁能用、用了什么，全程可追溯 |
| **管智能体** | 统一配置专家团、Skill、模型 | 确保全员使用经过审批的能力 |
| **管 Token** | 集中采购、按部门分配、额度限制 | 避免乱用浪费，成本可控可预测 |
| **管数据** | 企业级数据隔离，不用于模型训练 | 合同、报表、客户数据不会泄露 |

腾讯在企业版中的角色定位是"只当执行者，不当数据主人"——数据归你、管控归你、部署归你。

## ROI 可量化价值

企业版提供完整的数据看板，可以实时查看：

- 每个部门的 AI 使用频率和时长
- 不同专家团的使用热度排行
- Token 消耗趋势和成本分析
- 效率提升的量化指标

据实测数据，企业员工使用 WorkBuddy 后每天平均节省约 2 小时重复性工作时间。换算一下：100 人的团队，每天多出 200 小时的高价值工作时间。

**ROI 公式：每天节省 2 小时 × 团队人数 = 你的企业版 ROI**

## 从个人版到企业版的升级路径

升级过程不需要一次性全员切换，可以分三步逐步推进：

| 阶段 | 说明 |
|-----|------|
| **STEP 1 · 小规模试用** | 10 人以内团队先行体验，用 AI 处理日常文档、会议纪要、数据报表。不需要长周期培训，下载即用。 |
| **STEP 2 · 部门级推广** | 根据不同部门配置专属专家团，让市场、财务、HR、法务各取所需。后台统一管理，数据一目了然。 |
| **STEP 3 · 全员部署** | 通过企业版管理后台统一管控，追踪 ROI，持续优化使用策略。配套专属客户成功团队和培训服务。 |

如果你正在评估是否从个人版升级到企业版，可以先从一个小团队开始试用，验证实际效果后再逐步扩大范围。
