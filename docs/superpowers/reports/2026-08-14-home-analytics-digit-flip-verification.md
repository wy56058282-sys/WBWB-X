# 首页统计数字分位翻动验证

## 结果

- 聚焦测试：3 个文件，12 项通过。
- 全量测试：48 个文件，313 项通过。
- 内容链接：17/17，无断链。
- 替换资源检查：通过。
- VitePress 生产构建：通过（仅保留既有 chunk size 提示）。
- 旧路由生成与发布边界检查：通过。

## 行为合同

- 仅变化的数字位自下向上翻动，分隔符保持静止。
- 个位、十位、百位、千位及以上分别使用 360ms、410ms、460ms、500ms，并叠加 0ms、35ms、70ms、105ms 延迟。
- 首次取得真实统计值时执行一次翻动；Umami 指标口径与 5 分钟刷新周期不变。
- `prefers-reduced-motion: reduce` 下关闭翻动。
- 完整数值保留为无障碍文本，视觉拆分字符对读屏隐藏。

## 生产预览

- URL：`http://127.0.0.1:4192/?digit-flip-accept=1`
- 页面结构、导航和首页其他模块正常，无页面横向溢出。
- 本地生产构建未注入线上 Umami 环境变量，因此统计条按既有条件渲染合同隐藏；最终统计条可视验收在部署后的线上环境执行。
