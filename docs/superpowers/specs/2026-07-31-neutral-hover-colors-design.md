# WorkBuddy WB-X 全站中性悬停色设计

## 目标

将站内目前使用品牌绿色背景的悬停反馈统一调整为中性灰色，让品牌绿只承担选中、强调和键盘焦点等明确状态。

## 视觉规则

- 浅色模式的悬停背景使用浅灰色，与页面底色形成可感知但克制的对比。
- 深色模式的悬停背景使用深灰色，不使用绿色蒙层。
- 当前选中项、品牌图标、重点链接及既有品牌装饰继续使用 `#32E6B9`。
- 键盘 `focus-visible` 继续保留品牌绿色描边，悬停背景同时遵循中性灰规则。
- 不改变文字内容、链接目标、布局尺寸、圆角或位移动效。

## 适用范围

- `/wb-x/` 章节目录索引行。
- VitePress 左侧导航链接。
- 首页任务入口、阅读卡片和其他使用绿色背景作为 hover 反馈的站内交互项。
- 翻页链接、弹窗关闭按钮等已有独立悬停反馈的控件，仅在当前反馈为绿色时调整。

## 不在本次范围

- 当前页面或导航项的选中背景。
- 品牌按钮的固定绿色样式。
- 正文链接颜色、图标颜色和装饰性绿色。

## 验收标准

- 鼠标悬停时不再出现绿色背景填充。
- 当前选中状态仍能用品牌绿色清晰识别。
- 浅色与深色模式均有足够的悬停对比度。
- 键盘焦点清晰可见，且不依赖灰色背景单独表达。
- 现有链接、页面结构和交互行为不变。
- 相关测试、链接检查与 VitePress 生产构建通过。
