# 教程正文图片灯箱设计

## 目标

为 WorkBuddy WB-X 教程正文中的普通图片增加站内放大预览能力。读者无需离开章节页面即可查看流程图、界面截图和能力架构图的细节，同时保持现有链接图片、二维码、品牌素材与首页视觉的原有行为。

## 范围

### 包含

- VitePress 正文容器 `.vp-doc` 内、未被链接包裹的普通 `img`。
- 桌面端与移动端的全屏预览。
- 鼠标、触控和键盘操作。
- VitePress SPA 路由切换后的图片自动识别。
- 有 `alt` 时显示说明，无 `alt` 时不渲染空说明。

### 不包含

- 上一张、下一张或缩略图图库导航。
- 图片下载、旋转、缩放手势或多级缩放。
- 已位于 `a` 标签内的图片。
- 首页、导航、Logo、IP 形象、二维码弹窗等非正文图片。
- 逐篇修改 Markdown 图片语法。

## 方案选择

采用自定义 Vue 灯箱组件，不增加第三方依赖。

与引入 `medium-zoom` 相比，自定义组件可以明确控制键盘语义、焦点恢复、排除规则和移动端尺寸；与直接链接原图相比，它不会打断读者当前章节的阅读位置。

## 架构

新增独立的 `DocImageLightbox.vue`，由现有主题 `Layout.vue` 的 `layout-bottom` 插槽挂载。组件只负责三个边界清晰的任务：

1. 识别并增强当前页面内符合条件的正文图片。
2. 维护当前打开图片、说明文字和触发元素。
3. 渲染、关闭灯箱并管理键盘与焦点。

使用事件委托处理点击和键盘事件，避免为约 269 张现有图片逐一绑定监听器。组件挂载时执行一次扫描，并使用 `MutationObserver` 观察正文 DOM 更新，为 SPA 路由切换后出现的新图片补充可聚焦语义和放大光标。

## 图片识别规则

候选元素必须同时满足：

- 匹配 `.vp-doc img`。
- 不位于链接 `a` 内。
- 当前存在于文档中且具有可用的 `src`。

符合条件的图片获得：

- 专用增强 class。
- `tabindex="0"`。
- `role="button"`。
- 基于 `alt` 的中文可访问名称；无 `alt` 时使用通用“放大查看图片”。

链接图片不改写属性、不拦截点击，继续执行原跳转行为。

## 交互

### 打开

- 鼠标或触控点击正文图片。
- 图片获得焦点后按 Enter 或空格。

### 预览

- 使用全视口遮罩和居中的原图预览。
- 图片使用 `object-fit: contain`，最大尺寸为 `96vw × 90vh`，不拉伸、不裁切。
- 有非空 `alt` 时在图片下方显示说明；无 `alt` 时不保留说明区域。
- 灯箱使用 `role="dialog"` 和 `aria-modal="true"`。

### 关闭

- 点击明确的关闭按钮。
- 点击图片以外的遮罩区域。
- 按 Escape。

关闭后恢复页面滚动，并把焦点返回到原图片。打开期间阻止背景页面滚动。

## 视觉

- 正文候选图片使用 `cursor: zoom-in`。
- 遮罩使用高透明度深色背景，确保浅色截图边界清晰。
- 关闭按钮保持较大的触控区域和清晰的焦点样式。
- 灯箱层级高于 VitePress 导航、侧边栏和现有弹层。
- 动效只使用短时淡入淡出；在 `prefers-reduced-motion: reduce` 下关闭过渡。

## 状态与异常处理

- 图片加载失败时关闭预览，不显示损坏的占位图。
- 路由切换或组件卸载时关闭灯箱、恢复页面滚动并清理监听器。
- DOM 更新时只增强尚未处理的候选图片，避免重复写入属性。
- 恢复焦点前确认触发图片仍在文档中。

## 测试

新增回归测试覆盖：

- 普通 `.vp-doc img` 会被识别并获得键盘语义。
- 链接内图片不会被增强或拦截。
- 点击、Enter 和空格可打开灯箱。
- Escape、遮罩和关闭按钮可关闭灯箱。
- 有 `alt` 显示说明，无 `alt` 不显示空说明。
- 关闭后恢复触发图片焦点和页面滚动状态。
- CSS 包含桌面端、移动端和减少动画规则。
- 现有完整测试套件与生产构建继续通过。

## 验收标准

- 教程章节正文中的普通图片可在原页面放大查看。
- 链接图片、二维码、首页与品牌图片的行为不变。
- 桌面端和移动端均无横向溢出，图片完整可见。
- 键盘用户可以完成打开、查看和关闭流程。
- VitePress 页面切换后无需刷新即可继续使用。
