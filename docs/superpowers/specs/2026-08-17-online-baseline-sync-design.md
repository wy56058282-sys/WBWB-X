# 线上基线同步与阅读入口整合设计

## 背景

当前开发分支 `codex/reading-guide-navigation` 与线上发布分支已经形成两条并行历史。线上最新 `origin/main` 已包含小白书首页附录入口收拢、阅读卡片移动端对齐及版本内容更新；当前开发分支则包含尚未进入线上基线的「资料 / 阅读指南」导航调整和社区联系人二维码放大。

本次同步不把当前开发分支整体覆盖到线上基线，而是以最新 `origin/main` 为唯一内容基线，重新叠加本轮确认的四项改动。这样可以保留线上已经发布的新版阅读首页，同时避免把旧分支中的定制服务、社区二维码浮层等无关改动意外带回。

## 目标

1. 保留 `origin/main` 上现有的小白书首页、附录分组、移动端样式和版本内容。
2. 顶部导航将「指南」改为「资料」，链接到 `/resources/`。
3. 将现有阅读指南并入「开始阅读」，置于「小白书总览」正下方，名称为「阅读指南」。
4. 保留旧阅读指南地址的兼容跳转，并正确处理站点基础路径。
5. 将 `/community/contributing` 的两张联系人二维码卡片等比例放大 30px，即从 `140px` 调整为 `170px`。

## 基线与分支策略

- 基线固定为本次同步开始时的 `origin/main`：`9d2c0edafff189e30dd3407204f2e7dc6544f5f1`。
- 原分支 `codex/reading-guide-navigation` 保持可回退，不重写其历史。
- 在当前隔离工作区内从 `origin/main` 创建新的集成分支 `codex/sync-online-reading-guide`。
- 采用测试先行的手工重放方式，不整体合并或批量挑选旧分支提交。
- 只迁移本设计列出的文件级行为；如基线已有同类逻辑，以基线结构为准做最小增量修改。

## 信息架构与页面

### 顶部导航

顶部导航顺序保持不变，仅把原「指南」入口替换为「资料」：

- 首页
- 开始阅读
- 案例集
- 定制服务
- 资料
- 交流群

「资料」链接到 `/resources/`。首版资料页沿用标准文档布局，页面标题为「资料」，正文暂定为「资料整理中。」。

### 开始阅读

「开始阅读」侧边栏开头调整为：

1. 小白书总览
2. 阅读指南
3. 线上基线已有的各篇章、章节与附录

阅读指南迁移到 `/wb-x/reading-guide/`，正文内容保持不变。首页现有阅读路线入口同步指向新地址。

### 兼容跳转

以下旧地址永久跳转到 `/wb-x/reading-guide/`：

- `/reading-guide`
- `/reading-guide/`
- `/guide/reading-guide`
- `/guide/reading-guide/`

跳转目标复用项目现有基础路径逻辑，确保根路径部署和带 `SITE_BASE` 的部署都不会产生双斜杠、重复前缀或错误绝对路径。静态 `_redirects` 与构建生成的 HTML 跳转页保持一致。

## 联系人二维码尺寸

- `.wb-contact-card` 宽度从 `140px` 改为 `170px`。
- 卡片图片宽度同步改为 `170px`，高度继续使用 `auto`，保持原图比例。
- 保留现有 `24px` 间距、居中标签、点击查看大图和 flex 换行规则。
- 不修改顶部「交流群」二维码浮层、图片文件、联系人文案或链接。

## 明确保留的线上更新

- 小白书首页版本信息及线上现有文案。
- 第一条附录入口与正文之间的单条分割线。
- 后续附录入口的紧凑间距。
- 阅读卡片在移动端的对齐与响应式规则。
- `origin/main` 上当前存在的测试、构建和配置更新。

## 明确排除

- 当前旧分支中的定制服务页面改版。
- 社区顶部二维码浮层及其交互改动。
- 与本次导航、阅读指南、旧链接兼容、联系人卡片尺寸无关的配置或测试变更。
- 发布、合并到 `main` 或部署线上；这些动作需在本地验收后另行确认。

## 实现与验证顺序

1. 从 `origin/main` 创建集成分支并确认工作区未覆盖旧分支历史。
2. 先补充或调整导航、侧边栏、内容链接、旧路由和联系人卡片测试，确认测试在基线上按预期失败。
3. 以最小修改实现页面迁移、资源占位页、基础路径兼容跳转和 170px 卡片尺寸。
4. 运行聚焦测试、完整测试、内容链接与资源检查、默认生产构建及带基础路径的生产构建。
5. 使用当前应用内浏览器检查 `/wb-x/`、`/wb-x/reading-guide/`、`/resources/` 和 `/community/contributing` 的桌面及移动端状态。
6. 对照线上基线确认附录分组、版本内容和移动端阅读卡片未回退，并检查页面无水平溢出。

## 验收标准

1. 本地 `/wb-x/` 保留线上新版附录收拢和最新内容，不再出现旧分支的附录大块间距。
2. 顶部「资料」可进入 `/resources/`，占位内容正确。
3. 「阅读指南」位于「小白书总览」下方，并通过 `/wb-x/reading-guide/` 打开。
4. 首页阅读路线入口指向新地址，旧地址能在根路径和自定义基础路径部署中正确跳转。
5. 两张联系人二维码卡片均为 `170px` 宽，图片按比例显示，窄屏可自然换行且无横向滚动。
6. 未引入旧分支的定制服务、社区浮层等范围外改动。
7. 聚焦测试、完整测试、链接检查、资源检查和两种生产构建全部通过。
