# 定制服务诊断摘要布局设计

## 状态

- 日期：2026-08-16
- 状态：待书面规格确认
- 适用页面：`/help/`
- 调整范围：仅调整需求诊断首屏中“价格 / 时长 / 固定交付 / 商务微信”摘要的位置和响应式布局。

## 目标

把诊断摘要完整并入左侧主内容区，让右侧辅助列只承担“本页目录”导航，解决摘要与目录争夺空间、窄屏拥挤和视觉重心分散的问题。

## 布局方案

1. 保留现有标题、说明、`¥399 · 45 分钟 · 固定诊断结论摘要`和“开始需求沟通”按钮。
2. 将价格、时长、固定交付和商务微信状态组成一个独立的“诊断摘要”区块。
3. 摘要放在左侧主内容列内，紧接首屏介绍与按钮之后，不再作为首屏右侧列。
4. 页面右侧仅保留现有“本页目录”，不放价格、二维码或商务微信占位。
5. 不改价格、时长、交付内容、二维码资源、开放状态和转化流程。

## 响应式

- 宽桌面：摘要在左侧主内容列内横向排列；事实信息占主要宽度，商务微信占位占辅助宽度。
- 中等宽度：摘要仍在主内容列内，根据可用宽度收束为更紧凑的两列。
- 手机：价格、时长、固定交付与商务微信按阅读顺序纵向堆叠。
- 取消摘要现有用于视觉下移的 `50px` 位移，避免移动后留下额外空白或与后续内容重叠。

## 视觉与交互

- 延续当前页面的黑色文字、荧光绿强调、细分隔和直角布局语言。
- 不新增卡片套卡片、装饰背景或额外标题。
- 商务微信未就绪时继续显示不可操作的“商务微信即将开放”；不得渲染假二维码或空链接。
- 本次不改变右侧目录的 sticky 行为。

## 验收标准

- 在桌面端，诊断摘要的左右边界均位于主内容列内，与右侧目录无重叠。
- 右侧目录只包含页面锚点导航。
- 在 `1440px`、`900px` 和 `390px` 宽度下无横向滚动、遮挡或内容重叠。
- 摘要四项信息顺序保持为价格、时长、固定交付、商务微信。
- 页面价格、时长、交付文案和商务微信准备中状态保持不变。
- 自动化测试覆盖 DOM 归属、桌面布局、响应式堆叠和旧 `50px` 位移的移除。

## 非目标

- 不开放商务微信、报名表或付款入口。
- 不调整服务目录、FDE 模型、服务阶梯、申请流程和规则内容。
- 不修改其他页面的宽度、导航或视觉样式。
