# 首页主视觉整面翻转设计

## 目标

将首页绿色主视觉整体作为一张可翻开的正面卡片。卡片从主视觉左侧边缘向左翻开，露出覆盖完整主视觉面积的白色收藏与第三方推荐页面。右上角文字由 `WBWB-X` 改为 `WB-X`。

白色背面首期展示星火集、WorkBuddy、Z.ai 三个合作伙伴贴纸；结构需允许以后增加用户收藏、分类与更多第三方网站入口。

## 桌面端交互

- 正面包含左侧标题、说明、按钮以及右侧四个像素图标，所有内容作为一个整体翻转。
- 白色收藏与推荐面板固定在正面下方，覆盖完整主视觉。
- 正面以主视觉左边缘为轴，`transform-origin: left center`。
- 鼠标进入右下角触发区或点击触发区时，整面绕 Y 轴向左翻开。
- 鼠标离开主视觉、点击外部或按 Escape 时合上。
- 动画采用可中断 CSS transition，时长 280ms，曲线 `cubic-bezier(0.77, 0, 0.175, 1)`。
- 翻转期间保留已有焦点迁移、`inert`、`aria-hidden`、键盘和触屏操作规则。

## 页面结构

- `HeroStickerPage` 成为整个 `.wbx-hero__stage` 的交互外壳，而不是只包裹右侧图标区。
- `.wbx-sticker-page__cover` 内继续使用与当前主视觉相同的左右网格，因此关闭状态布局不变。
- `.wbx-sticker-page__inside` 是完整白色面板，使用可扩展的贴纸网格。
- 触发区仍位于主视觉右下角，命中区域不小于 72×72px。
- 正面右上角标记显示 `WB-X`。

## 移动端与减少动态

- `max-width: 960px` 时不执行 3D 翻转，改为正面淡出、白色面板淡入。
- `prefers-reduced-motion: reduce` 时使用 1ms 状态切换，不执行空间旋转。
- 所有状态不得造成横向滚动或把触发区移出视口。

## 可扩展性

- 合作伙伴数据继续来自 `heroPartners`，不把链接硬编码进模板。
- 白色面板使用网格布局，新增贴纸不要求改动翻转控制逻辑。
- 本轮不新增收藏的数据模型、登录、搜索或分类交互，只保留容器扩展能力。

## 验收标准

1. 打开时整个绿色主视觉翻转，包括左侧标题、按钮和右侧图标。
2. 翻转轴位于主视觉左边缘，不再存在中线或半页翻转。
3. 白色面板覆盖完整主视觉，并展示三个可点击合作伙伴贴纸。
4. 关闭后正面链接可用；打开后仅白色面板链接可用。
5. 键盘、触屏、外部点击、Escape 和焦点恢复行为不回退。
6. 桌面、移动端、暗色模式和减少动态模式均可用。
7. 右上角标记显示 `WB-X`。

## 测试策略

- 模板测试要求 `HeroStickerPage` 包裹完整主视觉内容，而不是只存在于 `.wbx-hero__art`。
- 样式契约测试要求整面 `rotateY`、左侧翻转轴以及 960px/减少动态降级规则。
- 品牌测试要求首页主视觉标记为 `WB-X`。
- 保留并运行现有 HeroStickerPage 行为测试。
- 运行全量测试、内部链接检查、素材检查和正式构建。
