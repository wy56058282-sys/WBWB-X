# 首页右半页整页翻转设计

## 目标

将首页主视觉右侧的局部掀角效果改为整页翻转。翻页书脊必须与主视觉布局的 50% 中线严格重合。右上角文字由 `WBWB-X` 改为 `WB-X`。

## 桌面端交互

- 主视觉保持左右各 50% 的双页布局。
- 白色合作伙伴贴纸页固定在右半页底层。
- 当前绿色图标页作为右半页封面，`transform-origin` 固定为 `left center`。
- 鼠标进入右下角触发区或点击触发区时，封面绕 Y 轴向左翻转，完整露出白色贴纸页。
- 鼠标离开主视觉区域、点击外部或按 Escape 时合上。
- 翻转使用可中断的 CSS transition，时长约 280ms，采用 `cubic-bezier(0.77, 0, 0.175, 1)`。
- 翻页期间保留已有焦点迁移、`inert`、`aria-hidden` 与键盘操作规则。

## 视觉结构

- 翻页容器覆盖右半页，不跨入左侧内容区。
- 中线只保留一条 1px 分隔线，不叠加额外边框。
- 封面正面继续显示四个黑底品牌绿像素图标、`WB-X` 和章节统计。
- 白色内页继续显示星火集、WorkBuddy、Z.ai 三个可点击贴纸。
- 页面翻转时允许轻微透视与阴影，但不增加弹跳或连续自动动画。

## 移动端与减少动态

- `max-width: 760px` 时不执行 3D 翻转，改为封面淡出、贴纸页淡入，保持现有可点击触发区。
- `prefers-reduced-motion: reduce` 时使用 1ms 状态切换，不执行空间旋转。
- 所有状态不得造成横向滚动或把触发区移出视口。

## 验收标准

1. 中线位置等于主视觉宽度的 50%，翻页轴与中线重合。
2. 打开时整张右半页翻转，不再使用局部 `clip-path` 掀角揭示。
3. 关闭后封面四个链接可用；打开后仅贴纸页链接可用。
4. 键盘、触屏、外部点击、Escape 和焦点恢复行为不回退。
5. 桌面、移动端、暗色模式和减少动态模式均可用。
6. 右上角标记显示 `WB-X`。

## 测试策略

- 更新样式契约测试，要求中线书脊、`rotateY` 整页翻转及移动端/减少动态降级规则存在。
- 更新品牌文案测试，要求首页主视觉标记为 `WB-X`。
- 保留并运行现有 HeroStickerPage 行为测试。
- 运行全量测试、内部链接检查、素材检查和正式构建。
