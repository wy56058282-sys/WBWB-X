# 首页机器人卡片跳转提需求设计规格

日期：2026-08-02

## 背景

首页 Hero 右侧的机器人像素卡片当前跳转到 Part 1 使用手册，并使用无障碍标签“查看 Part 1 使用手册”。用户希望该卡片改为进入“提需求”页面。

## 目标

- 点击首页机器人卡片后进入 `/help/`。
- 卡片的无障碍名称准确描述目标页面。
- 与顶部导航中的“提需求”入口保持一致。
- 不改变其余四张图标卡片及 Hero 视觉表现。

## 设计

在 `docs/.vitepress/theme/HomePage.vue` 中修改 `.wbx-icon-card--buddy`：

- `href` 使用现有 `withBase('/help/')`，兼容根域和 GitHub Pages 子路径部署。
- `aria-label` 改为 `前往提需求`。
- 保留当前机器人图标、CSS 类名、位置、旋转、动画、悬停和键盘焦点样式。

不使用页面内部锚点，避免提需求页标题变化导致链接失效。

## 范围

- 仅修改机器人卡片的目标地址与无障碍标签。
- 其他四张 Hero 图标卡片的地址与标签保持不变。
- 不修改顶部导航；它已使用 `/help/`。
- 不修改提需求页面内容。

## 验收标准

- 首页机器人卡片的最终链接为 `/help/`；设置站点 `base` 时仍由 `withBase` 正确添加前缀。
- 卡片 `aria-label` 为“前往提需求”。
- 首页仍有五张可访问的图标链接，其他四张链接不变。
- 现有测试、链接检查与 VitePress 生产构建通过。
- 桌面和 390px 视口下机器人卡片的视觉位置与交互效果不变。
