# 首页阅读路径标题区平板布局设计

## 目标

修复首页“阅读路径”标题区在约 817px 宽视口下被左右两栏挤压、标题和描述同时换行的问题。

## 响应式规则

- 桌面端（视口宽度大于 `900px`）保留现有左右布局。
- 平板与窄屏（视口宽度不大于 `900px`）改为上下布局：像素标签、标题、描述依次排列。
- 在 `761px–900px` 范围内，标题与描述各自保持单行展示。
- 手机端（视口宽度不大于 `760px`）继续允许标题与描述自然换行，避免溢出。

## 约束

- 不修改标题、描述或像素标签文案。
- 不修改下方四张阅读卡片。
- 不改变桌面端布局。
- 不通过缩小字体强行容纳文字；优先释放整行宽度。

## 验收标准

- 在约 `817px` 视口下，“四段路径，按你的目标进入”完整显示为一行。
- 描述位于标题下方，并完整显示为一行。
- 在 `900px` 以上恢复左右布局。
- 在 `760px` 以下文字可以自然换行且无横向溢出。
- 生产构建及相关响应式测试通过。
