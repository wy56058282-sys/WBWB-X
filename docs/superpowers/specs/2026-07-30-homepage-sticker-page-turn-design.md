# 首页合作贴纸翻页交互设计

## 目标

在首页主视觉右侧像素图标区域增加一个轻量的右下角揭页交互。默认状态继续展示现有绿色封面和四个可点击像素图标；揭页后展示暖白色合作贴纸页，贴纸可跳转至对应第三方网站。

该交互用于增加首页的探索感和合作品牌入口，不改变现有主视觉布局、像素图标链接或下方价值条。

## 内容

首版展示三张贴纸：

| 名称 | Logo 源文件 | 跳转地址 |
| --- | --- | --- |
| 星火集 | `/Users/nick/Desktop/星火集/品牌/星火集.svg` | `https://www.sparkx.zone/` |
| WorkBuddy | `/Users/nick/Desktop/星火集/品牌/workbuddy.svg` | `https://www.workbuddy.ai/` |
| Z.ai | `/Users/nick/Desktop/星火集/品牌/z.ai.svg` | `https://z.ai/subscribe` |

Logo 将复制到站点静态资源目录。贴纸数据由独立配置数组提供，后续新增合作方只需添加名称、Logo 和网址。

## 视觉设计

- 现有右侧绿色像素图标区作为封面，保持尺寸、位置和内部链接不变。
- 右下角增加约 `72 × 72px` 的透明触发区。
- 触发区以白色折角和简短提示表达“可以翻开”，不遮挡底部内容规模文字。
- 揭页后露出暖白色内页，使用黑色细边、硬阴影和轻微旋转延续像素印刷感。
- 星火集贴纸位于上方，WorkBuddy 位于左下，Z.ai 位于右下，三者保持足够间距和可点击面积。
- 封面翻开时，原有四个像素图标与绿色封面一起移动，不与贴纸页重叠。

## 交互

### 桌面端

1. 鼠标进入右下角触发区时开始揭页。
2. 动画从右下角向左上方展开，持续约 `260ms`。
3. 鼠标进入白色贴纸页后保持展开，便于点击贴纸。
4. 鼠标移出整个右侧主视觉区域后恢复封面。
5. 贴纸点击后在新标签页打开第三方网站。

### 触摸设备

1. 点击右下角折角展开贴纸页。
2. 点击折角、关闭控件或右侧区域外部恢复封面。
3. 展开后的贴纸可正常点击，不依赖悬停。

### 键盘与辅助功能

- 折角使用可聚焦按钮，具备明确的 `aria-label` 和展开状态。
- `Enter` 或空格切换展开状态。
- 展开后贴纸保持正常 Tab 顺序。
- `Escape` 恢复封面。
- 第三方链接使用 `target="_blank"` 和 `rel="noopener noreferrer"`。

## 动效

- 使用可中断的 CSS transition，不使用会从头重播的关键帧翻页动画。
- 翻页采用强缓出曲线 `cubic-bezier(0.23, 1, 0.32, 1)`，恢复采用平滑的缓入缓出曲线。
- 动画只作用于 `transform`、`clip-path`、阴影和必要的透明度。
- 用户启用 `prefers-reduced-motion: reduce` 时取消空间翻页，改为快速显示或隐藏白色内页。

## 组件边界

新增独立的 `HeroStickerPage` 组件，负责：

- 展开和关闭状态；
- 鼠标、触摸、键盘及区域外关闭行为；
- 封面插槽和贴纸数据渲染；
- 减少动态效果下的表现。

首页继续负责现有文案、按钮、像素图标和内容规模数据。翻页组件不读取全局状态，也不改变其他页面。

## 异常与降级

- Logo 加载失败时显示品牌名称文字，链接仍可使用。
- 不支持复杂裁切效果的浏览器显示简单的封面滑开效果。
- 禁用 JavaScript 时保留现有绿色封面和四个像素图标，不影响核心导航。

## 验收标准

- 默认状态与当前首页右侧视觉一致，四个内部链接仍可访问。
- 桌面端从右下角触发揭页，进入贴纸区时不会意外关闭。
- 移动端可通过点击完成展开和关闭。
- 三张贴纸均显示正确 Logo，并跳转到指定网站。
- 键盘可完成展开、访问贴纸和关闭。
- 减少动态效果模式下没有明显空间翻页。
- 首页在常用桌面与移动断点下无横向滚动、遮挡或布局跳动。
- 单元测试和生产构建通过。
