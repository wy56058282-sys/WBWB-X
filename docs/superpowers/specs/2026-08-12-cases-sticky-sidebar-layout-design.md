# 案例集 3:1 固定侧栏布局设计

## 目标

把案例集首页重构为清晰的主内容区与工具侧栏：桌面端左侧集中承载案例浏览，右侧持续提供搜索、分类筛选和投稿入口；移动端恢复单栏阅读顺序。保留现有案例数据、筛选行为、卡片内容和投稿条件逻辑。

## 桌面布局

- 页面主体使用四等分概念的 `3:1` 两栏网格，主栏与侧栏之间保留稳定间距。
- 左侧主栏依次包含：`WORKBUDDY COMMUNITY`、主标题、`CASE GALLERY / 浏览案例`、说明文字、案例卡片或无结果状态。
- 案例卡片仅在左侧主栏内排布；根据可用宽度保持可读的三列、两列与单列断点，不允许为了维持列数压缩到不可读宽度。
- 右侧工具栏依次包含：搜索框、分类标签筛选、投稿模块。
- 工具栏使用 `position: sticky`，顶部偏移需避开全局导航栏；滚动到投稿模块高度较大时，侧栏自身不能遮挡页面末尾内容。
- 搜索框、分类按钮和投稿模块左边缘统一对齐。

## 投稿模块

- 延续当前服务配置逻辑：配置有效独立投稿表单时显示表单入口；未配置时显示现有投稿二维码、说明和投稿指南入口。
- 二维码必须保留可点击查看大图、替代文本和说明文字。
- 投稿模块并入右侧侧栏，不在左侧主栏重复出现。

## 响应式行为

- `1024px` 及以下切换为单栏。
- 单栏顺序为：主标题与浏览标题、搜索与分类筛选、案例列表、投稿模块。
- 单栏模式取消 `sticky`，避免短视口中工具区遮挡内容。
- 搜索框使用可用全宽；分类按钮允许自然换行；二维码宽度不超过容器。
- 页面在桌面、平板和手机视口均不得产生横向滚动。

## 交互与无障碍

- 保留查询文字与分类组合筛选、清除筛选、卡片链接和投稿链接行为。
- 分类按钮继续使用 `aria-pressed` 表达选中状态，图标仅作为视觉辅助。
- 搜索输入、筛选按钮、案例卡片、二维码和投稿链接必须保留可见键盘焦点。
- 无搜索结果时，清除筛选按钮仍位于主栏并可恢复全部案例。

## 验收标准

- 桌面端主栏与侧栏宽度呈稳定 `3:1` 关系，侧栏滚动时固定且不遮挡导航。
- 左侧包含标题与全部案例卡片，右侧仅包含搜索、分类和投稿入口。
- 右栏各控件左对齐，二维码完整显示。
- `1024px` 及以下按规定顺序单栏展示，且侧栏不再固定。
- 搜索、分类组合、清除筛选、投稿条件状态和案例链接均正常。
- 相关组件测试、样式合同测试、排版测试及生产构建通过。

## 不在本次范围

- 不修改案例详情页侧边栏。
- 不修改案例内容、封面、分类或排序。
- 不改造投稿数据存储、支付或后台管理系统。
