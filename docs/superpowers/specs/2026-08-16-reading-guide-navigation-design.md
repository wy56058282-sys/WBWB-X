# 阅读指南归入「开始阅读」与「资料」入口设计

## 目标

重新整理顶部导航与阅读区的信息架构：将现有阅读指南归入「开始阅读」，让学习路线与小白书目录处于同一阅读体系；同时把原顶部「指南」入口改为「资料」，先提供明确的占位页面，为后续教学资料、模板和补充资源预留稳定入口。

## 信息架构

顶部导航保持现有顺序，仅替换一个入口：

- 首页
- 开始阅读
- 案例集
- 定制服务
- 资料
- 交流群

「资料」链接到 `/resources/`。

「开始阅读」侧边栏开头调整为：

1. 小白书总览
2. 阅读指南
3. 第一篇及后续现有篇章、章节与附录

「阅读指南」链接到 `/wb-x/reading-guide/`，位于「小白书总览」正下方，不改变其余目录顺序。

## 页面与路由

### 阅读指南

- 将现有 `docs/reading-guide.md` 内容迁移到 `docs/wb-x/reading-guide/index.md`。
- 页面标题、说明、正文结构和参与共创入口保持不变。
- 新地址为 `/wb-x/reading-guide/`，因此自然继承阅读区布局、侧边栏和样式。
- 首页现有「查看阅读路线」入口改为指向新地址。
- 原地址 `/reading-guide` 与 `/reading-guide/` 均永久重定向到 `/wb-x/reading-guide/`，避免旧书签、搜索结果和外部链接失效。

### 资料

- 新增标准文档页 `/resources/`。
- 页面标题为「资料」。
- 首版正文只显示「资料整理中。」；不提前承诺尚未确定的资料类型、发布时间或下载方式。
- 页面复用全站默认文档布局、主题、深浅色模式与响应式行为，不新增独立组件或视觉体系。

## 导航状态与交互

- 访问 `/wb-x/reading-guide/` 时，顶部「开始阅读」处于当前栏目状态，侧边栏「阅读指南」处于当前页面状态。
- 访问 `/resources/` 时，顶部「资料」处于当前页面状态。
- 所有入口保持现有键盘焦点样式和最小可点击区域。
- 移动端继续使用 VitePress 的折叠导航；新标签不得造成菜单溢出或遮挡。

## 兼容与内容边界

- 不修改小白书各篇章、章节与附录的名称、顺序或地址。
- 不重写阅读指南正文，不在本轮增加卡片、插图或新的交互。
- 不修改首页、案例集、定制服务和交流群的其他行为。
- 保留已有站点基础路径处理，新增内部链接必须使用项目现有的路径约定。

## 验证

- 自动化测试覆盖顶部导航文案与链接、侧边栏顺序、新旧阅读指南地址、首页入口和资料页内容。
- 内容链接检查确认站内不再指向旧阅读指南地址。
- 生产构建确认重定向文件、新页面和中文路径正常生成。
- 浏览器检查桌面端与移动端导航状态、侧边栏选中态、页面标题、暗色模式和无水平溢出。

## 验收标准

1. 顶部「指南」已改为「资料」，链接到 `/resources/`。
2. `/resources/` 显示标题「资料」和正文「资料整理中。」。
3. 「阅读指南」出现在「开始阅读」侧边栏的「小白书总览」正下方。
4. 阅读指南通过 `/wb-x/reading-guide/` 打开，并显示阅读区侧边栏。
5. 旧 `/reading-guide` 地址自动跳转到新地址。
6. 首页「查看阅读路线」进入新地址。
7. 现有篇章、案例、服务和社区入口不受影响。
8. 相关测试、内容链接检查和生产构建通过。
