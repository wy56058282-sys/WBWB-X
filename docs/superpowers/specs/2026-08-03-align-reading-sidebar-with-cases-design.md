# 小白书侧边栏对齐案例集样式设计

## 目标

让 `/wb-x/` 及其章节页面的侧边栏菜单复用 `/cases/` 的菜单视觉规范，统一菜单密度、圆角、悬停色与选中态，同时保留小白书自己的章节分组和滚动行为。

## 设计方案

采用方案 A：删除小白书阅读布局中针对菜单链接的尺寸覆盖，让菜单链接回落到全局案例集规范。

- 桌面端菜单链接使用 `2px 6px` 内边距和 `6px` 圆角。
- 取消小白书菜单链接的 `44px` 最小高度。
- 悬停和键盘聚焦继续使用 `--wbx-sidebar-hover-surface` 偏绿浅灰背景。
- 当前页面继续使用 `--wbx-accent` 品牌绿色背景和深色文字。
- 移动端继续复用全局较大的触控间距，不降低可点击区域。

## 保留范围

- 不修改侧边栏菜单文案、章节链接、分组顺序或展开状态。
- 保留小白书侧边栏边线、背景、独立滚动区域和滚动条样式。
- 保留篇章之间的分组分隔；仅把分组上下间距调整为与案例集视觉密度协调的尺寸。
- 不影响首页、案例集、提需求、阅读指南等其他页面。

## 验收标准

1. 小白书桌面侧边栏不再声明 `min-height: 44px` 或 `padding: 4px 12px`。
2. 小白书菜单链接最终使用案例集的桌面间距 `2px 6px` 和圆角 `6px`。
3. 悬停背景为 `--wbx-sidebar-hover-surface`，选中背景为 `--wbx-accent`。
4. 章节分组与侧边栏滚动功能保持不变。
5. 现有测试、相关回归测试和生产构建全部通过。
