# 首页任务标题分割线移除设计

## 目标

移除首页“你现在想让 AI 帮你做什么？”标题区域上方的横向分割线，让阅读路径卡片与任务入口之间的过渡更简洁。

## 修改范围

- 仅移除 `.wbx-section__heading--compact` 的 `border-top`。
- 保留该标题区域现有的 `padding-top: 18px`，不压缩上下内容间距。
- 保留下方 `.wbx-task-grid` 的顶部、左侧和卡片分隔边框。
- 不修改标题文案、功能卡片、响应式布局或其他页面样式。

## 验证

- 增加 CSS 回归断言，确认 compact 标题容器不再设置顶部边框。
- 继续确认任务网格自身的顶部边框存在。
- 运行相关 Vitest 测试、完整测试套件与生产构建。
- 在本地首页确认目标横线消失且下方网格边框正常。
