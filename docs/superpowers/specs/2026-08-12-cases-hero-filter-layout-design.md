# 案例集首屏筛选双栏设计

## 目标

将案例集首页首屏重排为与定制服务页一致的左右双栏信息结构，减少独立页内目录带来的重复导航，并让搜索与分类筛选在首屏成为明确的操作区域。

## 已确认方案

- 删除案例集首页右侧“本页目录”区域及其两个锚点链接。
- 桌面端首屏使用左右双栏：
  - 左栏保留 `WORKBUDDY COMMUNITY`、`WorkBuddy WB-X 案例集` 和简介。
  - 右栏放置 `CASE GALLERY`、`浏览案例`、搜索框和完整分类筛选。
- 首屏下方以 2px 黑色分隔线结束，分隔线后直接展示案例卡片网格。
- 搜索、分类选择、空状态与清除筛选逻辑保持不变。
- 分类按钮继续使用网站像素图标库；选中项显示确认图标，未选中项显示语义图标。
- `1024px` 及以下回落为单栏：标题区在上，筛选区在下；搜索框占满可用宽度，分类按钮自然换行。
- 保留案例投稿模块、案例卡片内容、数据源、链接和详情页行为，不在本次改动中重写。

## 视觉与布局合同

- 桌面首屏沿用定制服务页的双栏比例与节奏，左右栏顶部对齐。
- 标题字号、字重和正文排版继续遵循指南页基线。
- 英文眉题位于对应中文标题上方，不与中文标题重叠。
- 筛选区不使用卡片外框，不新增圆角容器；控件继续使用直角、2px 描边和荧光绿选中态。
- 删除目录后，案例网格使用主内容区完整宽度；桌面三列、紧凑桌面两列、手机一列的现有响应式策略保持不变。
- 页面在桌面、平板和手机均不得产生横向溢出。

## 可访问性与交互

- `浏览案例` 继续作为筛选区可访问标题。
- 搜索框保留可见标签、占位文本和高对比焦点环。
- 分类按钮保留 `aria-pressed`，图标标记为装饰性。
- 删除页内目录后不留下空白 `aside`、无效锚点或不可达焦点目标。

## 验证

- 组件测试验证目录被移除、筛选区位于首屏右栏且筛选逻辑未变。
- 样式测试验证桌面双栏、`1024px` 单栏断点、顶部对齐和既有 3/2/1 卡片网格。
- 生产构建后在 1440px、900px、390px 真实浏览器检查布局、筛选交互、焦点状态和横向溢出。
