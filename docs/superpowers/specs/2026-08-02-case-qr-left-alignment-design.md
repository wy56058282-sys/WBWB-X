# 案例集二维码左对齐设计

## 目标

将案例集首页共创区域的二维码卡片与上方正文内容左边缘对齐，修正当前居中布局造成的视觉断层。

## 设计

- 仅调整 `.case-co-create__qr` 的水平定位，由容器内居中改为左对齐。
- 保留二维码卡片当前宽度、内边距、边框、圆角、背景和文字样式。
- 保留二维码图片的尺寸、比例和点击放大行为。
- 移动端沿用相同左对齐规则，不改变共创区域的响应式内边距与阴影。
- 不修改共创区域正文、二维码素材或链接。

## 实现方式

将 `.case-co-create__qr` 的外边距从 `margin: 0 auto` 改为 `margin: 0`。不增加新的组件或断点规则。

## 验证

- 增加源代码回归测试，断言二维码卡片使用 `margin: 0`，且不再使用自动水平外边距。
- 运行完整 Vitest 测试套件。
- 运行 VitePress 生产构建。
