# 首页访问统计数据条设计

## 目标

在首页 Hero 下方、阅读路线之前增加一条真实访问统计数据条，让访问者看到网站当前活跃度与累计内容消费情况。数据来自 Umami Cloud，不使用演示数字或人工历史基数，也不在浏览器中暴露 API Key。

## 数据口径

- 今日访问：Umami `visits`，时间范围为北京时间当天 00:00 至当前时间。
- 今日浏览：Umami `pageviews`，时间范围同上。
- 累计访问：从统计脚本上线时开始至当前时间的全部 `visits`。
- 累计浏览：从统计脚本上线时开始至当前时间的全部 `pageviews`。
- 统计时区固定为 `Asia/Shanghai`。
- 不回填上线前历史数据，首次开始采集时四项累计值从 0 起步。
- 页面首次加载立即取数，之后每 5 分钟刷新一次。

## Umami 配置与公开边界

- 使用 Umami Cloud Hobby 方案。
- 在 Umami 中为 `wbx.sparkx.zone` 创建独立 Website，并在全站加载官方统计脚本。
- 创建只读 Share URL，只开放 Overview 和 Realtime 视图。
- 前端配置只包含 Website ID、Share URL 或公开读取所需的 share 标识；不得包含 Umami API Key、账户令牌或登录凭据。
- 数据请求封装在独立适配层中。实现阶段先验证 Umami Cloud 当前公开分享接口的请求格式与跨域响应；展示组件不直接依赖具体接口路径。
- 若公开分享接口无法安全、稳定地提供所需四项聚合值，则停止接入并重新确认服务端中转方案，不允许把私密 API Key 降级放入前端。

## 界面设计

- 数据条位于完整 Hero 区块之后、阅读路线区块之前，与首页主内容使用相同左右边界。
- 延续首页视觉语言：白色或主题面色背景、2px 黑色描边、直角结构、荧光绿状态强调、Silkscreen 像素字体数字或辅助标签。
- 桌面端为一行五区：状态区、今日访问、今日浏览、累计访问、累计浏览；区块之间使用细竖线分隔。
- 状态区显示绿色状态点和“实时统计”，不使用可能暗示秒级数据的 `LIVE` 文案。
- 移动端状态区独占一行，四项指标使用 2 x 2 网格；数字和标签不得截断或造成页面横向滚动。
- 数字采用千位分隔；大数保持完整可读，不使用含糊的人工缩写，除非布局验收证明必须缩写并另行确认规则。

## 状态与组件边界

- 新建独立统计展示组件，负责布局、加载态、成功态和失败态。
- 新建 Umami 数据适配模块，负责时间范围计算、公开接口请求、响应校验和统一数据模型转换。
- 首页仅负责放置组件，不把取数、定时器或 Umami 响应解析继续堆入 `HomePage.vue`。
- 组件挂载时立即请求；成功后启动 5 分钟定时刷新；卸载时清理定时器和未完成请求。
- 同一刷新周期只允许一个活动请求，避免慢请求叠加或旧响应覆盖新数据。
- 页面在后台时不主动轮询；重新回到前台且数据已超过 5 分钟时立即刷新。

## 加载、失败与降级

- 首次加载时四项数字显示等宽占位，不以 `0` 冒充尚未返回的数据。
- 请求失败时显示 `--`，状态文案改为“暂未同步”；保留最近一次成功数据时，可继续显示旧数据并标注同步状态。
- 响应缺字段、类型错误或出现负数时视为无效数据，不渲染异常数字。
- 失败不会阻塞首页其他内容，也不自动打开 Umami 分享页面。
- `prefers-reduced-motion: reduce` 下关闭数字更新过渡；正常模式仅使用轻微、不改变布局的数值淡入。

## 无障碍与隐私

- 统计条使用有意义的区域名称，指标标签与数值以普通文本呈现，不依赖颜色传达状态。
- 自动刷新不使用打断式 live region，避免每 5 分钟干扰读屏。
- 状态点为装饰元素并从辅助技术中隐藏。
- 只展示站点级聚合数字，不展示访客身份、IP、地域、设备或单页访问记录。
- 统计脚本配置遵循 Umami 的无 Cookie 默认采集方式；不启用 Session Replay 或 Heatmap。

## 测试与验收

- 单元测试覆盖北京时间当天边界、累计范围、响应解析、无效数据、并发请求保护、5 分钟刷新与卸载清理。
- 组件测试覆盖加载、成功、失败、旧数据降级、四项标签和无障碍名称。
- 验证桌面单行布局、移动端 2 x 2 布局、明暗主题、无横向溢出及减少动态效果模式。
- 生产验收确认全站只加载一次 Umami 统计脚本，Website ID 正确，页面浏览能进入 Umami Cloud。
- 生产验收确认首页展示值与 Umami Overview 在同一时区和时间范围内一致。
- 检查构建产物和浏览器网络请求，确保没有 API Key、账户令牌或其他私密凭据。
