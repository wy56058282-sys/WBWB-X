# 小白书总览页附录入口设计

日期：2026-08-13

## 目标

在 `/wb-x/` 的章节目录中，把目前合并展示的单一“附录 · 补充资料”入口拆为三个可直接访问的附录入口，让总览页与左侧附录导航保持一致。

## 信息结构

章节目录保留现有四篇内容，随后依次显示：

1. `A` — `附录 A · 常用指令模板`，说明为“整理可直接复用的常用指令”。
2. `B` — `附录 B · 场景速查表`，说明为“按工作场景快速找到实践路径”。
3. `C` — `附录 C · 个人版与企业版对比`，说明为“对比版本能力、适用对象与选择方式”。

每个入口直接链接到已经上线的对应附录目录页，不再经过附录总览中转页。

## 视觉与交互

- 复用现有 `.wbx-book-index__entry--appendix`、编号块、标题和说明样式。
- 三个入口按 A、B、C 顺序排列，与前四篇保持相同的裸列表行节奏。
- 不新增卡片、图标、颜色或额外交互。
- 保留键盘可聚焦和整行点击区域。

## 变更边界

- 修改 `docs/wb-x/index.md` 中的附录目录项。
- 更新 `tests/wb-x-index.test.ts` 对数量、标题、说明和目标路径的断言。
- 不修改附录正文、VitePress 导航配置、CSS 或其他页面。

## 验收

- 总览目录包含 7 项：4 篇正文与 A/B/C 三项附录。
- A/B/C 标题、说明、排序与本设计完全一致。
- 三个链接分别到达现有附录 A、B、C 页面。
- 聚焦测试、内部链接检查及生产构建通过。
