# 恢复小白书目录列表视觉设计

## 目标

将 `/wb-x/` 的章节目录恢复为用户确认的裸列表样式，去除后续引入的白色卡片感，同时保留当前内容、链接、附录和响应式修复。

## 视觉范围

- 四个篇章条目不使用白色背景、边框或圆角容器。
- 保留黑色方形编号 `01`–`04`、篇章标题与说明文字。
- 条目保持整行可点击，但不在悬停时横向位移。
- 附录继续作为下方独立条目，并保留其上方分隔线。
- 不修改页面标题、正文、链接地址或右侧页内导航。

## 侧边栏

- 保留现有紧凑菜单间距。
- 普通条目悬停和键盘聚焦使用偏绿背景 `#e4ece5`。
- 当前激活条目继续使用品牌绿色，不改变文字层级。

## 响应式行为

- 桌面端与移动端均采用无白色卡片的目录列表。
- 移动端保留当前两列结构：编号与文字内容。
- 长标题和说明可正常换行，不产生横向溢出。

## 验证

- 更新目录视觉回归测试，明确断言条目背景透明、无边框、无圆角及无位移动效。
- 保留并验证侧边栏偏绿色悬停变量。
- 运行相关 Vitest 测试与生产构建。
- 在本地预览检查 `/wb-x/` 桌面端和窄屏布局。

## 非目标

- 不回滚 `fb2ef50` 之后的其他提交。
- 不修改篇章文案、URL、附录内容或侧边栏信息架构。
- 不改动首页和其他阅读页面的卡片样式。
