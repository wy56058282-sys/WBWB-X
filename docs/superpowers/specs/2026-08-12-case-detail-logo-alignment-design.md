# 案例详情页 Logo 基线对齐设计

## 目标

案例详情页隐藏左侧栏后，正文左边缘不再紧贴页面边缘。桌面端以顶部文字 Logo 的左边缘为视觉基准，让返回入口、标题和正文统一对齐。

## 设计

- 仅作用于 `/cases/submissions/` 下的案例详情页。
- 桌面端将详情内容容器左右内边距设为 `40px`。
- “返回案例集”、文章标题和正文沿同一左侧基线排列。
- 保留当前宽版文档布局，不恢复案例目录侧栏。
- `959px` 及以下继续沿用 VitePress 现有响应式留白，不强制使用 `40px`，避免窄屏正文被压缩。
- 不修改案例正文、案例首页、投稿指南、小白书和定制服务页面。

## 验收标准

- 桌面端详情内容左边缘与顶部文字 Logo 左边缘误差不超过 `2px`。
- 返回入口、H1 和正文左边缘一致。
- 桌面、平板和手机均无页面横向溢出。
- 案例详情侧栏保持隐藏，返回入口仍可见、可聚焦、可点击。

## 测试

- 增加案例详情页专属 CSS 合同，锁定桌面 `40px` 留白和 `959px` 以下的响应式回退。
- 生产构建后在桌面、平板和手机视口量测内容基线与横向溢出。
- 运行案例详情聚焦测试、全量测试和 VitePress 生产构建。
