# 首页移动端细节优化设计

## 目标

在不改变桌面端首页的前提下，统一优化 `760px` 以下移动端 Hero、阅读路径卡片和资料下载区域的视觉定位。

## 适用范围

- 仅修改 `docs/.vitepress/theme/home.css` 中 `@media (max-width: 760px)` 及其更窄断点的规则。
- 保留现有组件结构、链接、文案、图片素材和交互动效。
- 桌面端与平板端现有布局保持不变。

## Hero 官网 IP

- `.wbx-hero__official` 的移动端底部定位由 `54px` 改为 `0`。
- `.wbx-hero__official-ip` 的移动端宽度由 `100px` 改为 `106px`。
- IP 图片底边与绿色价值区顶边的视觉间距为 `0px`。
- `workbuddy.ai` 标签尺寸、位置关系和悬停效果保持不变。

## Hero 图标卡片

- 第一篇目录书本卡片仅在移动端使用 `-30deg` 旋转角度。
- 工作系统进阶卡片仅在移动端向左移动 `10px`；使用 `right: calc(8% + 10px)`，避免与现有浮动动画的 `transform` 冲突。
- 其他图标卡片的位置和旋转角度保持不变。

## 阅读路径卡片

- 移动端网格保留三列：图标、正文、箭头。
- 箭头显示在最右列并垂直居中，不再隐藏或落到卡片左下方。
- `420px` 以下继续使用 `56px` 图标和较小间距，但仍保留箭头列。
- 四张阅读路径卡片使用同一规则。

## 资料下载区域

- 移动端资料区右侧图片区域的有效底部空间缩短 `10px`。
- IP 图片的宽度、比例和视觉位置不缩放。
- 允许图片底部按原尺寸自然超出缩短后的容器，不能裁切图片。
- 页脚文字与按钮布局保持不变。

## 验证

- 增加 CSS 回归测试，断言上述移动端尺寸、定位、旋转、三列网格和资料区底部收紧规则。
- 回归测试同时断言桌面基础规则未被改写。
- 运行完整 Vitest 测试套件和 VitePress 生产构建。
- 在 `390px` 与 `579px` 宽度下确认无横向溢出、IP 不裁切、箭头靠右。
