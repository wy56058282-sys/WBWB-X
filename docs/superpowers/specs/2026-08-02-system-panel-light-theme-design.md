# 首页系统区域浅灰主题设计

## 目标

将首页“FROM TASK TO TEAM”系统区域从深色面板改为参考图中的浅灰容器，在保留现有宽度、圆角和信息结构的前提下，提高页面整体一致性与阅读舒适度。

## 视觉方案

- 外层 `.wbx-system` 使用浅灰背景 `#F3F4F2`。
- 区域主标题、说明文字和右侧四格正文使用近黑色 `#0D100D`。
- 右侧 `.wbx-system__grid` 使用白色背景 `#FFFFFF`。
- 四格分隔线使用浅灰绿色 `#D9E0DC`。
- 像素标签和编号保留品牌绿色语义，但在白底上使用深绿色 `#087A61`，确保清晰可读。
- 保留当前 `20px` 圆角、桌面端 `52px` 左右缩进和移动端 `4px` 左右缩进。
- 下方绿色共创区域保持现状与通栏宽度，不纳入本次修改。

## 响应式行为

本次只改变颜色，不改变现有桌面双栏和移动端单栏结构。浅灰外层、白色四格和黑色正文需要在所有断点保持一致。

## 可访问性

- 正文采用近黑色配浅灰或白色背景。
- 品牌强调色采用深绿色，不直接使用高亮薄荷绿承载小字号文字。
- 不移除现有语义结构、标题关系或键盘行为。

## 测试与验收

- 样式测试锁定外层背景、正文颜色、四格背景、分隔线和强调色。
- 现有系统区域宽度与 `20px` 圆角测试继续通过。
- 全量 Vitest 测试通过。
- VitePress 生产构建成功。
- 在桌面和移动断点检查文字对比度、四格层级及与绿色共创区域的衔接。
