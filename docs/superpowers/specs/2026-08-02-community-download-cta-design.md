# 首页资料下载通栏设计

## 目标

将首页底部现有“参与共创 / 前往 GitHub”区域改造成资料下载入口。视觉参考 WorkBuddy 官网“开启 AI 办公新范式”板块，但延续 WB-X 当前字体、绿色品牌色和直角按钮体系，不复制官网素材。

同一批修改将上方系统区域标题从 `一次成功，不该只发生一次。` 更新为 `AI 时代，一起象限跃迁`，其他系统区域内容与布局保持不变。

## 内容与链接

- 像素标签保留：`BUILD IN PUBLIC · LEARN IN PUBLIC`。
- 主标题改为：`获取 WorkBuddy 小白书与配套资料`。
- 增加说明：`下载完整读本、案例资料与后续更新内容。`。
- 主按钮显示 `教学资料`，跳转 `https://pan.quark.cn/s/ca7b76d97d59?pwd=WPc9`。
- 页面不再单独显示提取码；分享链接继续携带 `pwd=WPc9` 参数。
- 次按钮显示 `参与共创`，跳转站内 `/community/contributing`。
- 删除现有 `前往 GitHub` 按钮及其仓库跳转。

## 布局与视觉

- 区域使用视口级通栏布局，左右延伸到浏览器边缘，不受首页内容区的横向内边距限制。
- 桌面端使用左右两栏：左侧为标签、标题、说明与按钮；右侧使用用户提供的透明背景 WorkBuddy IP 形象。
- 容器使用浅色背景与深色文字，避免与紧邻的浅灰系统区域混淆；使用绿色作为按钮和局部强调色。
- 删除右侧视觉区的绿色渐变底，左右两栏统一使用资料区域的浅灰背景。
- 取消资料区域外描边；左右内容分栏仍可通过背景差异建立层次。
- 资料区域与上方系统区域的距离在现有基础上增加 `20px`：桌面端由 `28px` 调整为 `48px`，移动端由 `18px` 调整为 `38px`。
- 桌面端资料区域实际高度在当前基础上缩小约 `30px`：容器与右侧视觉区最小高度由 `300px` 调整为 `270px`，左侧上下内边距由 `46px` 调整为 `31px`，IP 最大宽度由 `460px` 等比缩至 `424px`；移动端保持现有高度规则。
- 在上述基础上，桌面端资料区域高度继续由 `319px` 减少至 `299px`；IP 保持 `424px` 最大宽度和 `24px` 出框量，通过绝对定位避免继续撑高容器。
- 按钮沿用站内现有组件样式：主按钮为绿色实底外链，次按钮为深色或描边站内链接。
- IP 角色本体保持静止，不使用浮动或旋转动画。
- 桌面端 IP 舞台整体向下移动 `24px`，允许角色从资料区域底部出框；页脚增加 `24px` 顶部安全空间，避免遮挡产品与版权文字。移动端取消出框并保持角色收在容器内。
- 原始透明 PNG 作为唯一素材保存并完整静态显示，不裁切角色或爱心，不创建重复爱心图层，不使用任何 IP 或爱心动画。
- `教学资料` 使用品牌绿色实底、品牌绿色描边和黑色文字，悬停状态不得切换为白色文字。

## 响应式与可访问性

- 桌面端保持两栏，文字优先占据主要空间，装饰图形不覆盖按钮和正文。
- 资料区左侧文字与上方系统区域文字列对齐：大于 `1200px` 时基于 `1480px` 首页最大宽度动态计算；`1200px` 以下桌面端使用 `132px` 左边距；移动端继续使用 `24px`。
- 资料区主标题在桌面端使用 `36px` 并保持单行；`760px` 以下恢复自然换行并使用 `30px`，避免窄屏横向溢出。
- 窄屏改为上下排列：文字与按钮在前，缩小后的 IP 形象置于下方独立装饰区，不遮挡正文或操作。
- 夸克入口使用外链并在新标签页打开，设置 `rel="noopener noreferrer"`。
- 参与共创链接保留清晰的键盘焦点样式。
- IP 与爱心均为装饰图形，使用 `aria-hidden="true"`。

## 下载行为

- 夸克按钮使用真实分享地址，并带有链接内的提取码参数。
- 使用 `target="_blank"` 与 `rel="noopener noreferrer"`，保留当前小白书页面。
- 页面不展示提取码文字，用户通过携带 `pwd=WPc9` 的链接直接访问。
- 本次不新增下载统计、不把 PDF 文件提交到公开目录。

## 首页产品信息页脚

- 在资料下载通栏之后恢复首页产品信息。
- 左侧文案：`以真实场景为主线的 WB-X 实战读本`。
- 左侧同时保留来源链接：`Pixel icons by HackerNoon`，指向 `https://hackernoon.com/pixel-icon-library`。
- 右侧文案：`Copyright © 2026 WB-X.SparkX`。
- 页脚直接使用页面背景，不设置独立灰色背景、外框、卡片容器或分隔边框。
- 桌面端左右对齐；移动端改为居中排列并分行显示。
- 来源链接保留清晰的悬停与键盘焦点状态。

## 首页 Hero 官网入口

- Hero 右下角增加 WorkBuddy 官网入口，使用用户提供的透明 IP 图片。
- IP 上方显示黑底白字 `workbuddy.ai` 标签，标签与 IP 组成一个完整点击区域。
- 点击后在新标签页打开 `https://www.workbuddy.ai/`，并设置 `rel="noopener noreferrer"`。
- 桌面端将内容规模文字向左收，官网入口停靠右下角；移动端缩小入口，避免遮挡五张功能卡片和内容规模文字。
- 桌面端 IP 图片底边与下方绿色价值条贴合，垂直间距为 `0px`；移动端继续保留安全间距，避免覆盖内容规模文字。
- 官网入口悬停或键盘聚焦时 IP 保持静止；键盘聚焦仍保留清晰的焦点描边。
- 黑色 `workbuddy.ai` 标签单独参考方形图标卡片使用轻微上下浮动与阴影；IP 图片保持静止。悬停或聚焦入口时暂停标签动画，`prefers-reduced-motion` 下关闭动画。
- Hero 主标题上方的像素标签显示 `27 CHAPTERS / 4 PARTS / ∞ WORKFLOWS`，替换原有 `REAL TASKS · 27 CHAPTERS · OPEN SOURCE`。
- 删除右侧图标区底部重复的内容规模文字，只保留主标题上方的一组。
- 桌面端 Hero 文案区与图形区使用严格 `50% / 50%` 双栏，文案区右边界与整张 Hero 卡片中线重合；`960px` 以下继续使用单列布局。
