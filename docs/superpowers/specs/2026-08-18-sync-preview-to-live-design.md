# 预览版对齐线上版本设计

## 目标

以 `https://wbx.sparkx.zone/` 的实际渲染结果为权威基准，使本地预览在页面结构、导航、文案、资源链接和样式上与线上版本一致，同时完整保留当前未提交改动与尚未上线的服务页方案。

## 已确认的偏差

- 线上导航使用“资料”并指向 `/resources/`，本地仍使用“指南”并指向 `/reading-guide`。
- 线上首页显示“中国版 v5.3.13”和“国际版 v5.2.7”，本地显示“中文版”和“国际版”。
- 线上首页包含数据展示条，本地没有对应组件。
- 线上阅读指南位于 `/wb-x/reading-guide/`，本地仍使用旧路径。
- 当前功能分支落后于线上发布基线，且未提交的 `HomePage.vue` 修改覆盖了线上版本文案。

## 对齐策略

1. 精确列出当前已修改和未跟踪文件。
2. 仅将会影响对齐的 7 个已修改文件保存到一个带说明的 Git stash；不删除未跟踪文件。
3. 将已经通过线上页面关键内容验证的 `origin/main` 合入当前功能分支。
4. 保留当前分支已有的服务页设计与实施计划提交，但不把尚未上线的“第四类障碍”功能混入预览。
5. 暂不恢复 stash，使工作树首先呈现与线上一致的基线；stash 保留为可恢复备份。

## 变更边界

- 不重置或删除当前分支。
- 不删除未跟踪的审计、截图、计划或缓存文件。
- 不覆盖 stash 中的本地修改。
- 不引入线上没有的功能或视觉调整。
- 不执行部署，只更新并验证本地预览。

## 验证方法

- 运行与首页、导航、资源页、阅读指南和服务页相关的测试。
- 运行完整测试套件、链接检查、静态资源检查和生产构建。
- 重新加载本地预览，逐页比较线上与本地的 `/`、`/wb-x/`、`/resources/`、`/wb-x/reading-guide/` 和 `/help/`。
- 重点确认版本标签、导航文字与链接、首页数据条、下载链接、页面标题和主要区块一致。
- 若动态分析数据依赖线上环境变量，本地验证组件结构与降级状态，不伪造线上数据。

## 恢复方案

- 合并前的未提交修改保存在命名 stash 中，可通过 `git stash list` 定位。
- 如果整合失败，停止在冲突状态，不删除文件、不强制重置，并报告具体冲突。
- 若需要继续本地实验，可在对齐验证完成后从 stash 选择性恢复文件，而不是一次性覆盖线上基线。
