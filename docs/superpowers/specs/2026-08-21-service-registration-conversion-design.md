# 定制服务页报名转化闭环设计

## 状态

- 日期：2026-08-21
- 状态：待用户书面确认
- 页面：`/help/`
- 目标：以 `¥39` 双周工作坊为唯一首要转化入口，承接后续 `¥399` 需求诊断与企业定制项目。

## 业务路径

页面保持三阶段逻辑：工作坊体验 → 需求诊断 → 企业定制。所有“先参加工作坊”与“报名最近一期”按钮打开同一个报名二维码，不再跳转到嘉宾老师区。企业服务入口仍用于阅读后续服务说明，不与报名入口争夺主视觉层级。

工作坊三期 Tab 继续控制左侧活动信息、日期地点与右侧海报。报名二维码为三期共用，不随 Tab 切换；默认选中第二期。815、829 海报继续打开各自公众号详情，912 海报保持不可点击。

## 报名交互

- 桌面端：按钮悬停或键盘聚焦时显示快速二维码预览；点击按钮打开固定二维码对话框，避免鼠标移开后消失。
- 触屏端：点击按钮直接打开二维码对话框，不依赖 hover；提示“长按识别或截图后在微信中识别”。
- 对话框使用原生可访问语义（`role="dialog"`、`aria-modal="true"`、可读标题），包含二维码、`¥39 / 人`、最近一期日期和关闭按钮。
- 支持关闭按钮、遮罩点击与 `Escape` 关闭；打开时焦点进入关闭按钮，关闭后返回原触发按钮；打开期间锁定页面滚动。
- 页面存在多个报名触发器，但只渲染一个对话框实例，由共享状态记录当前触发元素，避免二维码内容或开关状态不一致。
- 不提交表单、不接入支付、不收集联系方式或其他个人信息。

## 页面转化强化

- 顶部工作坊模块保留主按钮“报名最近一期”和次按钮“了解企业服务”；主按钮打开二维码。
- 三阶段路径的第一张卡增加明确的“扫码报名工作坊”动作，第二、三阶段只说明后续转化条件，不新增并列主按钮。
- 企业定制区的“先参加工作坊”复用报名对话框；“了解企业服务”继续滚动到企业定制区。
- 手机端在顶部工作坊主按钮离开视口后显示底部固定报名条，内容为“最近一期 · ¥39 / 人”和“扫码报名”；返回工作坊区域或打开对话框时隐藏。
- 固定报名条避开现有右下角快捷入口，考虑底部安全区，不遮挡正文；桌面端不显示。
- 遵守 `prefers-reduced-motion`，触屏端不增加缩放动画。

## 匿名事件统计

复用现有 Umami 客户端能力，只有全局追踪函数存在时才发送事件；统计失败不得影响交互。事件不包含姓名、微信号、设备标识或二维码内容：

- `service_workshop_tab_select`：属性仅含期次 ID（815 / 829 / 912）。
- `service_registration_open`：属性含入口（hero / path / enterprise / mobile_sticky）和当前期次 ID。
- `service_workshop_detail_click`：属性含期次 ID。
- `service_enterprise_view`：属性含入口 hero。

每次明确点击记录一次；hover、focus、关闭弹层和滚动曝光不记录，避免噪声。

## 实现边界

- 在现有 `ServicePage.vue` 内维护 `registrationOpen`、活动触发元素和移动端固定条可见性；工作坊期次仍由 `selectedWorkshopIndex` 唯一派生。
- 报名弹层拆为页面内单一组件或同文件单一结构，不复制二维码 DOM。
- 保留当前工作坊数据、嘉宾老师、路径卡悬停、海报悬停、企业权益和其他页面行为。
- 本轮不新增外部 API、站内支付、预约表单、用户账户、CRM 或线上部署。

## 验收标准

- 桌面 hover/focus 可预览二维码，点击可固定打开；手机点击能打开完整对话框。
- 所有报名 CTA 打开同一对话框，关闭方式、焦点恢复和滚动锁定正确。
- 手机固定报名条只在合适滚动区间出现，不与快捷入口重叠，无横向溢出。
- 切换三期不改变共用二维码；当前期次信息在对话框与匿名事件中保持一致。
- 815、829 详情链接和 912 不可点击行为不回归。
- 自动化覆盖对话框状态、键盘关闭、触发来源、移动端固定条、事件载荷及降级行为。
- 运行定制服务聚焦测试、完整项目检查、生产构建，并完成桌面和移动端浏览器验收。

## 默认与假设

- “最近一期”沿用页面默认选中的第二期（2026-08-29）；用户切换 Tab 后，对话框显示当前选中期次，但二维码保持共用。
- 粗门小程序二维码继续使用现有 `workshop.registrationQrPath`，无需生成或替换素材。
- 移动端固定条断点沿用站点移动端规则（不高于 640px）；平板保持普通页面按钮。
- 该设计补充并取代旧规格中与当前 `¥39` 工作坊入口冲突的转化描述，不改变已确认的合作伙伴免费诊断 3 次权益。
