# WorkBuddy WB-X 阅读区视觉系统第一轮设计

## 目标

为 `/wb-x/` 小白书阅读区建立统一、克制且可持续维护的视觉分隔体系。正文主要依靠留白形成层级，组件使用单层表面与一致的交互反馈，同时保留 WB-X 的像素品牌语言。

## 本轮范围

- `/wb-x/` 小白书总览。
- 第一篇至第四篇的导读与 27 章正文。
- 附录总览、附录 A 与附录 B。
- 上述页面共用的左侧导航、正文目录、分页导航、代码块、表格、提示块与 Mermaid 图表容器。
- 浅色模式、暗色模式和移动端表现。

## 不在本轮范围

- 首页主视觉、首页像素图标和首页重点海报。
- `/cases/`、`/help/`、`/reading-guide/` 与 `/community/` 页面。
- 文案、章节顺序、链接目标、URL、导航信息架构和 Mermaid 图表内容。
- 新增 Vue 组件或重写 VitePress 默认布局。

## 视觉原则

1. 浅灰背景用于区分区域，不承担主要内容卡片的强调。
2. 标题、正文、说明与组件之间主要通过留白形成层级。
3. 删除重复分割线、相邻边框和多层容器描边；同一区域只保留一条必要边界。
4. 普通卡片统一使用白底、浅灰描边和一致圆角。
5. 悬停反馈统一使用中性灰，不使用绿色背景。
6. 品牌绿 `#32E6B9` 只用于当前状态、章节编号、键盘焦点与关键操作。
7. 像素字体只用于编号和短标签；正文、标题和说明继续使用全站正文字体。

## 设计变量

现有变量继续作为唯一来源，并补齐阅读区需要的语义变量：

- `--wbx-paper`：页面与侧边栏浅灰底。
- `--wbx-surface`：普通卡片和内容容器表面；浅色模式为白色。
- `--wbx-line`：单层浅灰描边与必要分割线。
- `--wbx-hover-surface`：中性灰悬停背景。
- `--wbx-accent`：品牌绿 `#32E6B9`。
- `--wbx-ink`：主文字和图标。
- `--wbx-muted`：说明文字。
- `--wbx-reading-radius`：阅读区统一圆角，固定为 `8px`。
- `--wbx-reading-space`：阅读区基础间距，固定为 `8px`，组件使用其整数倍。

暗色模式保留同一语义，但将 `paper / surface / line / hover` 映射到分层深灰，不扩大品牌绿面积。

## 组件规则

### 正文区域

- 页面背景保持浅灰，正文不再包裹额外白色大卡片。
- 一级区块依靠 `48px` 上下间距与标题建立层级；相邻普通段落不添加分割线。
- `h2` 仅在确有章节切换需要时保留单条浅灰上边界；避免标题上方同时出现容器边框和横线。
- 正文链接继续使用品牌相关文字色，但不使用绿色底色。

### 左侧导航

- 侧边栏保持浅灰背景与右侧单条浅灰边界。
- 普通链接透明底、统一 `8px` 圆角，并提供一致的水平和垂直内边距。
- 悬停和鼠标聚焦使用中性灰；键盘 `focus-visible` 使用品牌绿轮廓。
- 当前条目使用品牌绿背景和深色文字，是侧边栏唯一的大面积绿色状态。
- 分组之间只保留一条浅灰分割线；移除标题底部、帘幕和容器之间的重叠边界。
- 滚动条使用浅灰、窄轨道和圆角滑块，不穿过 Logo 区域。

### `/wb-x/` 章节目录

- 保留 `01 / 02 / 03 / 04 / A` 的 50px 黑色编号方块与品牌绿文字。
- 每个入口使用单层白色卡片、1px 浅灰描边和 `8px` 圆角。
- 标题与说明依靠字号、字重和间距区分，不增加内部边框。
- 悬停使用中性灰卡片背景和轻微位移；编号颜色不变。
- 附录通过前置间距与一条浅灰分割线区分，不增加第二层外框。

### 代码块、表格、提示块与 Mermaid

- 均使用白色或对应暗色表面、1px 浅灰描边和 `8px` 圆角。
- Mermaid 图只保留一个外层容器边界，内部 SVG 不再增加卡片描边。
- 代码块语言标签和提示块类型可使用品牌绿文字，但不使用绿色大底。
- 表格表头使用浅灰区域底色；行悬停使用中性灰。

### 分页与页脚

- 上一页、下一页使用白底、浅灰单边框和统一圆角。
- 悬停使用中性灰，不改变链接目标和方向信息。
- 编辑信息、更新时间与分页之间依靠间距区分，避免连续横线。

## 响应式规则

- 桌面端保持现有正文最大宽度和侧边栏宽度，不改变内容信息架构。
- 平板和移动端减少横向内边距，但保持 `8px` 圆角与至少 `44px` 的交互高度。
- 章节目录标题与说明自然换行，编号方块不缩小。
- 表格和代码块允许容器内横向滚动，不让页面整体出现水平滚动。

## 可访问性

- 所有交互项保留清晰的 `focus-visible` 状态。
- 当前状态不能只依靠颜色表达，同时保留字重或已有的 VitePress 活动状态语义。
- 主文字、说明文字、边框与背景在浅色和暗色模式中保持可读对比。
- 遵循 `prefers-reduced-motion`，关闭非必要位移过渡。

## 实现策略

- 采用“设计变量 + `/wb-x/` 局部 CSS 覆盖”，不新建 Vue 组件。
- 将阅读区规则集中在主题样式中，并使用 `/wb-x/` 页面结构选择器限制作用域。
- 首页样式继续留在 `home.css`，本轮不得修改首页主视觉规则。
- 先以测试锁定颜色职责、单层边界、圆角和作用域，再进行最小样式修改。

## 验收标准

- `/wb-x/` 页面能明确区分页面底、普通表面、悬停表面和当前状态。
- 普通卡片为白底、浅灰单描边、`8px` 圆角；不存在可见的双边框。
- 侧边栏普通悬停为中性灰，当前条目保持品牌绿。
- 正文不依赖大量横线分隔，标题和段落层级主要由留白表达。
- 章节目录、代码块、表格、提示块、Mermaid、分页使用一致的表面与圆角规则。
- 首页主视觉及非 `/wb-x/` 页面无视觉回归。
- 浅色、暗色、桌面、平板、移动端和键盘导航均通过检查。
- 已跟踪测试、内容链接检查和 VitePress 生产构建通过。
