# 首页访问统计数字翻动动效设计

## 背景与目标

首页访问统计条已经展示今日访问、今日浏览、累计访问和累计浏览，并每 5 分钟刷新一次数据。当前数值直接替换，数据更新时缺少反馈。

本次为四项数值增加逐位向上翻动的过渡，让用户能感知数据发生变化，同时保持现有统计结构、刷新策略、错误回退、视觉尺寸和响应式布局不变。

## 已确认交互

- 数字按位向上翻动，并按数位使用轻微不同的速率：个位约 360ms、十位约 410ms、百位约 460ms、千位及以上约 500ms。
- 相邻数位错峰约 35ms 启动，整组动画控制在约 600ms 内结束。
- 只有发生变化的数字位参与翻动；未变化的数字保持静止。
- 千分位等分隔符保持静止，不参与翻动。
- 首次成功加载时，真实数字从下方进入；不模拟从 0 递增的虚假计数。
- 后续刷新时，从旧数字翻到新数字。
- 动画不循环，不增加悬停或点击交互。
- `prefers-reduced-motion: reduce` 下关闭位移动画，直接显示最新数值。

## 组件设计

新增一个仅负责数值呈现的小组件 `AnalyticsFlipValue.vue`，由 `HomeAnalyticsStrip.vue` 的四个指标复用。

组件接收格式化后的显示字符串，例如 `12,355`，并将其拆为两类 token：

- 数字 token：进入固定宽度、单行裁切的数字窗口。
- 分隔符 token：直接静态渲染，不创建翻动层。

数字位从右向左按位对齐。这样 `999` 变为 `1,000` 时，个位、十位、百位仍对应相同数位，新增长度从左侧出现，不会导致所有旧数字被误判为位置变化。

每个数字窗口同时容纳离场数字和入场数字：旧数字向上离开，新数字从下方进入。Vue 使用稳定的数位键和当前字符键触发局部过渡。相同字符保持原节点，不重播动画。组件按从右向左的数位索引设置受控的动画时长和延迟，使个位响应更快、高位稍慢，同时避免整组动画拖沓。

加载态 `···` 和无数据态 `--` 继续使用现有静态文本，不拆成数字窗口。请求失败但已有历史数据时，继续显示上一组数值，不触发无意义动画。

## 视觉与布局

- 沿用现有像素字体、字号、颜色和右对齐方式。
- 数字窗口使用等宽 `1ch` 约束，避免动画过程改变指标单元宽度。
- 翻动仅使用 `transform` 和 `opacity`，不同数位通过 CSS 自定义属性接收时长和延迟，不触发布局重排。
- 数值容器保持单行、固定行高和裁切，旧值与新值不会同时撑高统计条。
- 不改统计条边框、阴影、标签、LIVE 状态、桌面四列和移动端两列布局。

## 无障碍

- 视觉数字层设置 `aria-hidden="true"`。
- 每个 `dd` 保留一份视觉隐藏的完整格式化数值，供辅助技术一次性读取。
- 不为每个数字位创建 live region，避免屏幕阅读器逐字播报。
- 现有统计同步状态 `role="status"` 保持不变。
- 减弱动效模式下不执行位移或透明度动画。

## 数据与异常边界

- 沿用 `Intl.NumberFormat('zh-CN')` 的格式化结果。
- 支持数值位数增加和减少，例如 `999` 到 `1,000`、`10,000` 到 `999`。
- 支持一次刷新中多个数位同时变化。
- 保留 5 分钟刷新、页面重新可见时补刷新、并发请求保护和组件卸载时取消请求。
- 接口错误时沿用现有 stale/error 行为，不清空已经展示的数据。

## 测试与验收

自动化测试覆盖：

1. 首次加载由占位内容切换为格式化数值，并生成数字窗口。
2. 更新后只有字符变化的数位获得翻动过渡，未变化数位复用原节点。
3. 千分位分隔符为静态节点。
4. 位数增加和减少时仍从右向左正确对齐。
5. 完整格式化值仍可被辅助技术读取，视觉数字不重复朗读。
6. 加载、错误和 stale 状态继续符合现有合同。
7. CSS 包含固定数字窗口、360–500ms 的分位 transform 动画、约 35ms 的错峰延迟和 reduced-motion 覆盖。

浏览器验收覆盖桌面与移动端：确认数值刷新时统计条高度、列宽和后续内容位置不跳动，长数字不溢出，明暗主题均清晰，减弱动效模式直接切换。

## 非目标

- 不改 Umami 数据源、统计口径或刷新频率。
- 不增加实时推送、计数递增模拟、声音或循环动画。
- 不调整首页其他模块、统计条文案或整体视觉结构。
- 不引入第三方动画依赖。
