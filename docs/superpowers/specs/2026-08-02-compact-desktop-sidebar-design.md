# 桌面侧栏紧凑化设计规格

日期：2026-08-02

## 背景

当前小白书与案例集的桌面侧栏菜单纵向空间偏大。菜单正文已经使用合适的 14px 字号与 24px 行高，主要问题来自链接的上下内边距与条目外边距，导致单行条目约 50px、双行条目约 74px，浏览较长目录时信息密度不足。

## 目标

- 提高桌面侧栏的信息密度，让更多章节在首屏可见。
- 保持现有字号、可读性、层级关系和交互反馈。
- 小白书与案例集侧栏使用同一套视觉规则。
- 不降低移动端菜单的触控友好性。

## 设计

仅在桌面断点（视口宽度不小于 960px）调整 `.VPSidebarItem .link`：

- 字号保持 `14px`。
- 行高保持 `24px`。
- 外边距从 `2px 0` 调整为 `0`。
- 内边距从 `7px 10px` 调整为 `2px 6px`。
- 单行菜单项目标高度约 `36px`。
- 双行菜单项目标高度约 `60px`。

移动端沿用现有间距，继续保留较大的触控区域。

## 交互与范围

- 保留当前选中项的背景、文字颜色与圆角表现。
- 保留 hover、focus-visible 与键盘导航反馈。
- 不修改侧栏宽度、分组结构、菜单文案或折叠行为。
- 规则同时覆盖 `/wb-x/` 与 `/cases/` 的 VitePress 侧栏。

## 验收标准

- 在宽度不小于 960px 的页面中，单行和双行菜单项高度分别约为 36px 和 60px。
- 在 390px 等移动视口中，菜单触控区域尺寸不因本次调整缩小。
- 当前项、悬停和键盘焦点状态正常。
- 小白书与案例集侧栏样式一致。
- 现有自动化测试、链接检查与 VitePress 构建通过。
