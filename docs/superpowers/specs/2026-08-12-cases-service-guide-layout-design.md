# 案例集与定制服务指南式布局设计

## 目标

以指南页面 `/reading-guide` 为布局参照，统一案例集 `/cases/`、定制服务 `/help/` 与指南页的外层内容宽度、左右留白和纵向节奏，同时保留案例画廊与服务页面各自的信息结构。

## 案例集

### 页面骨架

- 桌面端采用“左侧主内容 + 右侧页内目录”的指南式双栏骨架。
- 右侧目录沿用指南页面的视觉样式、吸附行为、当前项反馈和键盘可访问性。
- 目录项固定为“浏览案例”和“提交案例”，分别链接现有 `#case-gallery` 与 `#submit-case`。
- 删除页头中重复的横排“浏览案例 / 提交案例”导航。
- 平板和移动端隐藏右侧目录，主内容恢复单列并使用指南页的安全边距。

### 内容宽度与节奏

- 外层最大宽度、正文列与目录列比例参考指南页，不再使用独立的全宽画廊容器。
- 页头、浏览区、筛选控件、案例网格与投稿区之间的间距参考指南页章节间距。
- 保留案例卡片桌面、平板、移动端 `3 / 2 / 1` 响应式规则；列数按实际主内容宽度切换，不允许挤压文字或产生横向溢出。
- 保留搜索、分类、空状态、投稿入口和全部文案。

## 定制服务

### 宽度与模块间距

- 页面总宽度和左右留白与指南页一致。
- 页头、价格信息、问题、交付物、排除项、流程、付款、规则和相关案例之间的纵向节奏参考指南页正文章节。
- 不增加右侧页内目录，保留现有服务信息结构和阅读顺序。
- 不修改价格、时长、项目抵扣、付款开放状态、表单条件、隐私规则或任何业务文案。

### 标题字重

- 主标题、二级标题和正文分别使用与指南页相同层级的字重。
- 同级模块标题必须一致，不得出现同一层级忽粗忽细。
- 保留像素字体眉题作为区块识别信号。

### 列表与分隔线

- “适合带着这些问题来”列表关闭浏览器原生列表圆点，仅保留已注册的像素勾选图标。
- 删除原生圆点带来的多余缩进，图标与文字垂直对齐。
- 删除模块之间重复的整宽分割线，模块主要通过统一留白区分。
- 灰色“本次诊断不包含”区块上下不得叠加额外整宽边线。
- 列表项、流程步骤和数据条目内部仍可保留必要的细分隔线。

## 响应式与无障碍

- 桌面端验证案例右侧目录吸附且不遮挡内容。
- 紧凑桌面和平板验证目录隐藏后主内容正确扩展。
- `390x844` 下两页均不得出现页面级横向滚动、裁切或控件重叠。
- 目录、搜索、分类、链接与按钮必须保留可见键盘焦点。
- 浅色和深色主题均使用现有站点变量，不增加新依赖。

## 验收标准

1. 三个页面的外层宽度与左右留白具有一致视觉基线。
2. 案例集桌面端出现指南式右侧目录，页头不再重复导航。
3. 定制服务同级标题字重一致，模块间距与指南页一致。
4. 问题列表只显示一个像素图标，不显示原生圆点。
5. 定制服务模块间无重复整宽分割线，内部必要细线仍清楚。
6. 所有现有业务内容、筛选行为、链接和支付封闭逻辑保持不变。
7. 自动化测试、生产构建及桌面/移动端浏览器验收通过。
