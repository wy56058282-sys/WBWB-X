# 首页阅读卡片移动端对齐设计

## 目标

修正首页“四段路径”卡片在移动端的纵向对齐：头像顶部与中文主标题顶部对齐，右侧箭头底部与标签行底部对齐。

## 范围

- 仅影响 `max-width: 768px` 的首页阅读卡片。
- 四张阅读卡片使用同一套规则。
- 桌面端结构、字号、尺寸、悬停效果和链接行为保持不变。
- 不改变卡片文案、图标、标签或 DOM 顺序。

## 布局

- 卡片仍为三列网格：头像、正文、箭头。
- 移动端网格项目改为顶部对齐。
- 头像使用固定顶部偏移，跳过 `PART` 元信息行，使头像顶边与中文主标题顶边对齐。
- 箭头使用自对齐和固定顶部间距，下移到标签行，并以标签底边为视觉基准。
- `max-width: 420px` 保留现有较小头像和间距，只覆盖对齐位置。

## 验收

- 482px 宽视口中，四张卡片头像顶边与各自中文主标题顶边视觉误差不超过 2px。
- 箭头底边与标签行底边视觉误差不超过 2px。
- 卡片之间不重叠，页面无横向溢出。
- 桌面端阅读卡片 computed styles 不变。
