# 案例集与定制服务视觉统一设计

## 目标

让案例集与定制服务页面使用首页已经建立的 WorkBuddy WB-X 视觉语言，同时保留两个页面现有的信息结构和全部内容。统一后，用户应能明确感知三个页面属于同一产品，而不是三套独立模板。

## 适用范围

- 案例集首页 `/cases/`
- 定制服务页 `/help/`
- 两个页面已有的桌面、平板、移动端布局与明暗主题
- 不修改案例详情页内容结构，不删减文案，不改变现有业务流程

## 统一规则

### 内容容器

案例集和定制服务共用 `1280px` 最大内容宽度，并使用相同的 VitePress 容器层级和响应式左右边距。案例集不得另行解除内层容器限制；宽屏下内容居中，窄屏下保持既有安全边距且不得产生页面级横向滚动。

### 标题与文字层级

- 页面主标题采用首页式高字重、紧凑行高和零字距。
- `WorkBuddy WB-X` 品牌词保持强字重，中文标题按可用宽度自然换行。
- 像素字体眉题继续作为页面和区块识别信号，颜色使用品牌绿。
- 正文继续使用站点正文变量，不缩减内容，不使用营销页式超大留白。

### 按钮、筛选与标签

- 明确操作统一使用直角按钮、`2px` 黑色描边和首页同源的悬停位移或阴影反馈。
- 主操作使用黑底白字或荧光绿强调；筛选选中态使用荧光绿。
- 控件保留稳定高度与可见焦点轮廓，文字不得导致容器尺寸跳动。
- 案例标签继续保持紧凑，不改造成大面积装饰卡片。

### 图标

- 勾选、状态、步骤等界面图标优先使用网站现有像素图标库。
- 图标为装饰时使用 `aria-hidden`；可访问名称由相邻文字提供。
- 不新增手绘 SVG、Unicode 符号或另一套图标风格。

### 分隔与布局节奏

- 区块采用首页式黑色强分隔与站点变量细分隔相结合。
- 收紧眉题、标题、说明、操作区之间的垂直距离，但保持信息分组清楚。
- 案例卡片保持桌面三列、平板两列、移动端一列。
- 定制服务保留首屏双列、服务条目和流程结构，仅统一视觉表达。

## 响应式与主题

- 桌面端验证 `1440x900` 和紧凑桌面宽度，确保标题、操作和卡片不重叠。
- 移动端验证 `390x844`，确保单列、可点击目标、自然换行和零横向溢出。
- 浅色与深色主题均使用现有 CSS 变量，荧光绿、黑色描边和文字对比必须清晰。
- 不改变首页结构；仅将首页作为视觉基准并做回归检查。

## 验收标准

1. 案例集与定制服务的有效内容宽度和左右边距一致。
2. 两页主标题、按钮、标签、分隔线和图标明显属于首页同一视觉体系。
3. 页面内容、链接、筛选、支付开放状态及业务文案均无行为回归。
4. 桌面、平板、移动端无重叠、裁切或页面级横向滚动。
5. 键盘焦点、悬停状态、明暗主题和现有自动化测试通过。

## 测试策略

- 先补充样式合同测试，覆盖共享宽度、标题字重、直角 `2px` 控件和像素图标约束。
- 运行案例集与定制服务聚焦组件测试。
- 运行完整测试、内容链接检查、资源检查和生产构建。
- 使用 fresh production preview 完成桌面与 `390x844` 浏览器视觉验收。
