# 全站导航与案例页固定右栏设计

## 目标

- 首页、指南、案例集、案例详情和定制服务使用一致的桌面导航几何：Logo 区宽度、搜索框起点、背景与毛玻璃效果一致。
- 案例集右栏作为完整单元吸顶，搜索框、投稿说明、二维码和投稿按钮不得拆散或被顶部导航遮挡。
- 案例筛选结果变化不得导致右栏跳动。

## 导航设计

- 在桌面断点统一导航标题区宽度和搜索区位置，不再按页面是否带 `has-sidebar` 分别打补丁。
- Logo 区统一使用半透明纸张色背景与 `16px` 模糊；导航菜单、文案、链接与移动端结构保持不变。
- 移动端沿用当前紧凑导航，不强制显示桌面搜索框。

## 案例右栏设计

- 右栏内部顺序保持为：搜索框、投稿标题与说明、二维码、辅助说明、投稿指南按钮。
- 桌面端仅在右栏完整高度小于可用视口高度时启用 `position: sticky`。
- 吸顶偏移取导航实际渲染高度加 `24px`，不用仅依赖静态 CSS 变量。
- 导航高度、窗口尺寸或右栏内容变化时重新计算；筛选卡片只改变左栏，不改变右栏基准。
- `1024px` 及以下停用吸顶，右栏回到自然文档流。

## 验收

- 1440px：五类页面 Logo 左边界、搜索框起点和导航高度一致；案例右栏吸顶后搜索框完整可见，与导航至少间隔 `24px`。
- 900px、390px：无吸顶遮挡、无横向溢出，搜索与投稿内容顺序正确。
- 切换全部案例分类及输入/清除搜索时，右栏顶部坐标不跳动。
- 明暗主题下毛玻璃背景、文字和焦点状态清晰。
- 为导航几何、动态吸顶判定和响应式边界补充自动化测试，并完成生产构建与真实浏览器验收。
