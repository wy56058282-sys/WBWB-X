# 双维度知识首页与资料入口设计

## 背景与目标

当前首页以 WorkBuddy X 与 OPC 白皮书为核心，适合单一内容品牌，但难以自然容纳 Codex、FDE、DeepSeek Harness 等新增电子材料。

本阶段把首页升级为通用的 AI 实践知识入口，让用户可以从两个并列维度开始：

- **从工具开始**：横向、综合地掌握 WorkBuddy、Codex 等工具，并进入跨场景实践。
- **从角色开始**：纵向、针对性地围绕 OPC、FDE、AI 体验设计师等角色组织学习路线。

两个维度不是连续步骤，也不要求用户同时选择。用户可任选一个入口开始；同一份资料通过标签同时出现在对应工具与角色下。

## 第一阶段范围

### 包含

- 重构网站首页首屏，使其从 WorkBuddy 专属表达变为通用 AI 实践知识入口。
- 在首页提供“学一门工具”和“成为一种角色”两个同权入口。
- 将原“四段路径”改为通用路径：选方向、读材料、做案例、建系统。
- 把 `/resources/` 从占位页升级为电子资料目录，按工具和角色展示内容。
- 工具入口至少包含 WorkBuddy、Codex 和“搜索其他工具”。
- 角色入口至少包含 OPC、FDE 和 AI 体验设计师。
- 保留现有 `/wb-x/`、`/opc/`、`/cases/`、`/tools/` 与 `/services/` 路由和正文。
- 保留首页已有任务分类、工作坊、数据统计和社区转化区，但将它们放在通用入口之后，作为次级内容。

### 不包含

- 不建设登录、注册、收藏、阅读进度同步或用户数据库。
- 不把选择工具与选择角色做成强制问卷或连续向导。
- 不把新增 PDF 自动拆成网页版章节。
- 不在未确认公开发布授权前，把用户提供的第三方 PDF 复制到公开目录或提供下载链接。
- 不重写现有白皮书、案例集、工具集或企业服务的内部结构。

账号体系保留为后续阶段：只有当收藏、跨设备同步或个性化推荐成为真实需求时再建设，避免首次访问即要求注册。

## 信息架构

### 顶部导航

第一阶段在现有导航中增加“电子资料”，链接到 `/resources/`。其他现有入口保持可访问，不在本阶段引入多级导航或下拉菜单。

建议顺序：

1. 首页
2. 电子资料
3. 开始阅读
4. OPC 专区
5. 案例集
6. 工具集
7. 企业服务
8. 交流群

### 首页结构

1. **通用首屏**
   - 品牌眉题：AI 实践知识库。
   - 主标题：从一门工具，或一个理想角色开始。
   - 简介明确两个入口并列、无需注册。
   - 主操作指向 `/resources/#tools`，次操作指向 `/resources/#roles`。
2. **双维度入口**
   - 工具区：WorkBuddy、Codex、其他工具搜索入口。
   - 角色区：OPC、FDE、AI 体验设计师。
   - 工具使用站点品牌绿，角色使用辅助蓝；每个维度同时用标题和说明区分，不能只依赖颜色。
3. **通用四段路径**
   - 选方向：选择工具或角色。
   - 读材料：进入电子书、白皮书与指南。
   - 做案例：通过真实任务验证所学内容。
   - 建系统：把成功经验沉淀为工作流、Skill 或团队方法。
4. **现有次级区块**
   - 任务分类、工作坊、统计和社区区按现有行为保留。
   - 删除或改写仅把首页描述为 WorkBuddy 白皮书的文案，但不删除 WorkBuddy 内容本身。

### 电子资料页

`/resources/` 是两个维度的共同目录，而不是新的强制选择步骤。

- `#tools`：工具目录和工具搜索。
- `#roles`：角色目录。
- `#library`：电子材料列表。
- 每份资料显示封面、标题、出品方、简短说明、页数或章节数、工具标签和角色标签。
- 有有效公开地址时显示“在线阅读”或“打开 PDF”；无公开地址时显示“资料准备中”，不得生成空链接或虚假下载按钮。
- 搜索只过滤工具名称、资料标题和标签；没有结果时显示明确空状态。

## 内容模型

新增一个静态、带类型的资料目录数据源，供首页入口和资料页共同使用。数据不从页面组件中重复维护。

### 工具

- `id`
- `name`
- `summary`
- `href`
- `status`

### 角色

- `id`
- `name`
- `summary`
- `href`
- `status`

### 电子材料

- `id`
- `title`
- `publisher`
- `summary`
- `cover`
- `pageCount` 或 `chapterCount`
- `toolIds`
- `roleIds`
- `href`
- `format`
- `availability`

工具、角色和电子材料通过稳定 `id` 关联。`href` 为空时，组件必须根据 `availability` 呈现不可点击状态。

## 组件边界

### `learningCatalog.ts`

唯一静态数据源，定义工具、角色、电子材料及其类型。它不处理界面状态。

### `HomeLearningGateway.vue`

负责首页通用首屏、双维度入口和通用四段路径。它只消费目录数据并生成链接，不负责搜索和用户状态。

### `ResourcesPage.vue`

负责 `/resources/` 的工具目录、角色目录、资料列表和本地搜索。搜索状态只存在于当前页面，不写入账号或远端服务。

### `HomePage.vue`

继续作为首页编排容器。用 `HomeLearningGateway` 替换现有 WorkBuddy 专属首屏和阅读路径，保留任务、工作坊、统计与社区区块。避免在已经较大的文件中继续堆叠入口逻辑。

## 交互与数据流

1. 首页从 `learningCatalog.ts` 读取推荐工具和角色。
2. 点击工具或角色进入 `/resources/` 对应锚点或已有专题路由。
3. 资料页读取同一数据源，并根据搜索文本在浏览器本地过滤。
4. 点击可用资料进入现有网页或 PDF；不可用资料保持非交互状态。
5. WorkBuddy 和 OPC 继续分别进入 `/wb-x/` 与 `/opc/`，不改变原阅读体验。

本阶段没有网络请求、账号状态或持久化用户数据。

## 视觉与响应式规则

- 延续现有首页的宽内容容器、圆角、品牌绿、像素眉题、卡片悬停和明暗主题变量。
- 不进行彻底换肤；通过新的信息层级和双入口结构降低 WorkBuddy 专属感。
- 工具与角色在桌面端双列并排；`960px` 以下改为单列。
- 工具和角色卡在桌面端三列、移动端单列，文字不得截断关键信息。
- 桌面验证 `1440x900`，移动端验证 `390x844`。
- 所有交互目标有键盘焦点状态；颜色分类必须同时配合标题或文字标签。
- 尊重 `prefers-reduced-motion`，新入口不增加循环动画。

## 文案原则

- 首页先回答“你可以从哪里开始”，不再先介绍 WorkBuddy 产品能力。
- “工具”强调横向综合能力，“角色”强调纵向针对性路线。
- WorkBuddy、Codex、OPC、FDE 和 AI 体验设计师使用准确名称。
- 未上线内容使用“资料准备中”，不使用容易被误解为可点击的行动文案。

## 异常与边界处理

- 目录引用不存在的工具或角色 `id` 时，测试失败，不在界面静默忽略。
- 缺少封面时使用统一的文字封面占位，不加载破图。
- 缺少公开地址时不渲染链接元素。
- 搜索结果为空时提供清除搜索的提示。
- 所有内部链接使用 `withBase`，兼容根路径和 GitHub Pages 子路径部署。

## 验收标准

1. 首页首屏不再以“WorkBuddy X 与 OPC 白皮书”为唯一主标题。
2. 用户无需登录即可从工具或角色任一维度进入内容。
3. 工具与角色是并列入口，不出现“第一步、第二步”或强制组合流程。
4. WorkBuddy、Codex、OPC、FDE 和 AI 体验设计师均有清晰入口或明确的“资料准备中”状态。
5. `/resources/` 同时展示工具、角色和电子材料，并支持本地搜索。
6. WorkBuddy X、OPC、案例集、工具集、企业服务和工作坊现有入口无回归。
7. 新增第三方 PDF 在未确认授权时不会进入公开构建产物。
8. 桌面与移动端无重叠、裁切或页面级横向滚动，浅色和深色主题可读。
9. 键盘操作、焦点状态和减少动画偏好有效。
10. 聚焦测试、完整测试、内容链接检查、资源检查和生产构建通过。

## 测试策略

- 为资料目录增加数据完整性测试，验证稳定 `id`、关联有效性、可用状态与链接一致性。
- 更新首页测试，断言通用标题、双维度入口和四段通用路径。
- 增加资料页测试，覆盖工具搜索、角色展示、可用与不可用资料状态、空结果提示。
- 更新导航测试，断言“电子资料”入口及现有路由保留。
- 运行现有首页、阅读、案例、工具和服务相关回归测试。
- 运行完整测试、内容链接检查、资源检查和生产构建。
- 使用本地生产预览完成 `1440x900`、`390x844`、浅色与深色视觉验收。

## 后续阶段

以下能力只有在第一阶段稳定后单独设计：

- 登录注册、收藏和跨设备阅读进度。
- 根据“工具 × 角色”组合生成个性化路线。
- 更多工具与角色的独立专题页。
- 获得授权后的新增 PDF 在线阅读与下载。
- 内容后台、投稿审核和自动索引。
