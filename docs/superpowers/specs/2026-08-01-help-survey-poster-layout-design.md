# Help Survey Poster Layout Design

## Goal

让 `/help/` 的场景问卷卡片完整适配 `1560 × 1936` 纵向海报，使图片铺满可用宽度，同时保持原始比例、二维码清晰度和移动端适配。

## Scope

- 保持问卷卡片最大宽度 `560px`、内边距、边框、圆角和品牌绿投影不变。
- 保持当前海报文件、链接目标、替代文字和点击查看大图行为不变。
- 移除图片 `max-height: 560px` 限制，让图片使用 `width: 100%` 和自然高度按比例展示。
- 不裁切、不拉伸图片，不修改页面其他内容和卡片。

## Responsive Behavior

- 桌面端：海报铺满卡片图片区域宽度，按 `1560:1936` 比例自然增高。
- 移动端：卡片随页面宽度缩小，海报继续保持原比例，不产生水平滚动。

## Verification

- 样式契约测试确认图片不再设置最大高度，并保留全宽与等比展示。
- 运行相关测试、内容链接检查和 VitePress 生产构建。
- 在本地预览检查海报无裁切、无拉伸，且卡片宽度没有影响正文布局。
