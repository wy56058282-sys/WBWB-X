# 小白书附录入口紧凑分组设计

## 目标

将小白书总览页底部的附录 A、B、C 入口收拢为一个视觉连续的紧凑入口组，减少分割线与空白造成的割裂感，同时保留每个附录清晰、独立的导航能力。

## 范围

- 仅调整 `/wb-x/` 总览页附录 A、B、C 三个入口的布局样式。
- 三个入口继续纵向排列，并置于同一个连续分组中。
- 删除 A/B/C 条目之间的横向分割线。
- 缩小条目上下间距，使三项在视觉上更靠近。
- 每个入口仍保持整行可点击，并保留键盘焦点状态。
- 保留现有字母标识、标题、说明和目标链接。

## 不在本次范围

- 不修改四篇正文章节入口。
- 不修改附录 A、B、C 的页面内容或 URL。
- 不处理中国版、国际版产品名称的外部链接。
- 不修改侧边栏、页面标题、更新时间或底部翻页导航。

## 视觉规则

- 附录组与上方第四篇入口之间继续保留一次区块间隔，用于区分正文与附录。
- 附录组内部不显示横向边框或分隔线。
- 三个条目共享相同高度、内边距和对齐方式。
- 字母徽标保持现有 50px 尺寸和荧光绿色字符。
- 悬停与键盘聚焦沿用当前文本强调与高对比焦点样式，不产生位移。
- 移动端保持单列、整行点击，不出现横向溢出。

## 验收标准

1. `/wb-x/` 中仅存在三个附录入口，顺序为 A、B、C。
2. 三个入口标题、说明、链接目标与当前版本完全一致。
3. A/B/C 条目之间没有横向分割线。
4. 附录组与第四篇之间仍有清晰但不重复的区块间隔。
5. 每个附录入口的整行都可以点击，并可通过键盘聚焦。
6. 桌面和移动端均无重叠或横向溢出。

## 测试策略

- 更新 `tests/wb-x-index.test.ts`，锁定附录入口数量、顺序、内容和链接。
- 增加样式合同，断言附录内部无分割线、组首保留区块间隔、条目高度与交互状态稳定。
- 运行相关测试、完整测试与 VitePress 生产构建。
- 在桌面与移动视口检查附录组间距、整行点击和横向溢出。
